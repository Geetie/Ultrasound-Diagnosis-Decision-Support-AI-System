## 二、逐个证据（原文引用）

### 1. TN-SCUI 2020 — 标签是病理，但**许可封死**

**标签类型问题（本任务的核心疑问）——答案是"病理"**，但证据不在 Dataset 页，而在设计文档 PDF：

> **Dataset 页只说标注方式，不提病理**（这正是容易被误判为 B 类的地方）：
> "The annotation of the classification task is in CSV file with a header of ID (denotes for patient ID) and CATE (0 refers to Benign, and 1 refers to Malignant)."
> —— https://tn-scui2020.grand-challenge.org/Dataset/

> **设计文档 PDF 明确写病理**（Zenodo 3715942 §Annotation characteristics）：
> "The classification annotation was based on **the biopsy result of each patient**."
> —— https://zenodo.org/records/3715942（文件 `ThyroidNoduleSegmentationandClassificationinUltrasoundImages.pdf`，第 0 处 biopsy 上下文）

**致命问题是许可，不是标签**：
> "The publish right of this DATASET is limited to the purpose of this CHALLENGE ONLY due to the ethical approval was obtained. **No publication rights will be given on the dataset images apart from this challenge.** The participants will NOT be able to use the dataset images in any other publication or study."
> —— 同上 Dataset 页 + 首页

**另外两个坑**：
- 类别是**人为均衡**的："The training, validation and test cases are chosen according to **equal class distribution** of benign and malignant." → 无法据此还原真实患病率。
- 规模自相矛盾：Dataset 页写 "3644 US nodular thyroid images of 3644 patients"，设计文档写 "the dataset to-be-released contains a training set of 4,000 cases and a test set of 500 cases"。**以 Dataset 页的 3644 为准**。

**结论**：A 类标签成立，但**法律上不可用**。作为"能不能拿来算漏诊率"的答案是否定的。

### 2. TN5000 — 当前最优可下载 A 类

> "the types of the annotation of the nodule, i.e. the malignant or benign, is determined according to **FNA biopsy and pathological results**, which is far more reliable than that only be confirmed by the assessments of TI-RADS."
> —— Scientific Data 2025, DOI 10.1038/s41597-025-05757-4, PMC12357846

> "which consists of 5,000 ultrasound images of thyroid nodule, including **3,572 malignant cases and 1,428 benign cases**. Although the number of malignant cases is a little more than that of the benign cases in our dataset, we have tried our best to make a **rough balance** between them"
> —— 同上 Data Records

**两个必须写进结论的减分项**：
1. **患病率被严重扭曲**（恶性 71.4%）。漏诊率 = P(恶性|系统判良性)，它本身不依赖患病率，但应**报告为"在 71% 恶性富集样本上的漏诊率"**，不能外推为临床漏诊率。
2. **病理细节被抹除**："all identifying information, including names, genders, ages, **pathological numbers and other detailed information of biopsy results** for patients have been erased" → 只剩二分类，无病理亚型、无 FNA 前/手术病理区分。
3. 全文 **`follow-up` 命中 0 次** → 无 C 类。

**可信度加成**：该论文自己的 Table 1 对本清单多个候选做了同行评议式评价，可直接引用：
> | Dataset | Images | FNA biopsy | Publicly available |
> |---|---|---|---|
> | DDTI | 637 | Only for the malignant nodules | ✓ |
> | TN3k | 3493 | No mentioned | ✓ |
> | TN-SCUI2020 | 4554 | ✓ | **Only for a competition** |
> | ThyUS2Path | 8508 | ✓ | × |
> | TN5000 | 5000 | ✓ | ✓ |

> "**DDTI dataset conducted the FNA biopsy confirmation only for the malignant nodules**, TN3k dataset was annotated by volunteers without any mention of whether the FNA biopsy was performed"

⚠️ **必须并列记录的矛盾**：TN5000 作者称 DDTI 对恶性结节做过 FNA 确认；但我**实测 DDTI 全部 390 个 XML，`reportbacaf`（BACAF = FNA 报告）字段 0/390 填充**（见第 8 条）。可能是 Kaggle 分发版与原始站点版本不同。**以我实测的分发版为准**。

### 3. ThyUS2Path — 金标准最硬（全手术切除），但患病率同样扭曲

> 标题即 "An ultrasonography of thyroid nodules dataset with **pathological diagnosis annotation** for deep learning"

> "**Histological labels were obtained according to the histological diagnosis report of the corresponding tissue slides.**"

> 入组条件（这是它比 TN5000 更硬的原因——**全部手术切除**）：
> "(1) **hemi- or total thyroidectomy**, (2) maximum nodule diameter 2.5 cm, (3) examination by conventional US and real-time elastography (RTE) within 1 month before surgery, (4) no previous thyroid surgery or percutaneous thermotherapy"
> —— Scientific Data 2024, DOI 10.1038/s41597-024-04156-5, PMC11585535

> 构成："the first batch includes **6,005 thyroid images from 601 patients**, and the second batch contains 2,503 thyroid images from 241 patients. The training dataset comprises 601 patients, of which **218 are benign and 383 are malignant**, as indicated by histological reports."
> —— figshare DOI 10.6084/m9.figshare.27021604 官方摘要（经 DOI 内容协商实取）

> Batch1 n=601（Benign 218/36.3%，Malignant 383/63.7%）；Batch2 n=241（Benign 100/41.5%，Malignant 141/58.5%）

**关键限制**：全为手术病例 → 良性 36–41% 是"被切掉的良性"，即**已过穿刺/评估筛选的高危良性**，与真实筛查人群完全不同。**`follow` 命中 1 次且为无关文本 → 无随访**。

⚠️ 与 TN5000 论文的"ThyUS2Path 不公开(×)"冲突：本文自述 "available at the public figshare repository"。
**该冲突已由实测解决**：`https://ndownloader.figshare.com/articles/27021604/versions/1` 返回 HTTP 200 / 1,640,036,355 B，解压得 `batch1_image.rar`+`batch2_image.rar`，其中两张 label 表共 **842 例**（601+241），`histo_label` 分布 0=318 / 1=524。
→ **ThyUS2Path 确实公开可下**；TN5000 论文表格里的"×"是错的（或指当时尚未发布）。

### 5. DDTI — 本报告最重要的"打假"结论

Kaggle 页面副标题写着 "Thyroid Ultrasound Images to Classify **Benign&Malign** Cases"，**实测不成立**。

我实际下载 `ddti.zip`（18,036,883 B）并解析了全部 **390 个 XML / 480 张图**：

**XML 字段全集 = 9 个**：`age, sex, composition, echogenicity, margins, calcifications, tirads, reportbacaf, reporteco`

**字段填充率（实测）**
| 字段 | 填充 | 比例 |
|---|---|---|
| age | 304/390 | 77.9% |
| sex | 305/390 | 78.2% |
| composition | 200/390 | 51.3% |
| echogenicity | 200/390 | 51.3% |
| margins | 297/390 | 76.2% |
| calcifications | 299/390 | 76.7% |
| **tirads** | 298/390 | 76.4% |
| **reportbacaf**（FNA 报告） | **0/390** | **0.0%** |
| reporteco | 21/390 | 5.4% |

**tirads 取值分布**：`4a=85, 4b=75, 4c=56, 2=38, 5=30, 3=14`（无 1/6）

**决定性证据**：
- `reportbacaf` 是关键——BACAF 即 FNA（Biopsia por Aspiración con Aguja Fina）。**390 例全空**。
- `reporteco` 仅 21 例且是自由文本，如 `"Nodule 1"`, `"ARROW: TRACHEA"`, `"First FNA on feb. 2014 Bethesda 3"` —— 无结构化良恶性。
- 全 390 个文件里出现 `malign|benign|cancer|carcinoma|neopl|suspi` 关键词的文件数：**0/390**。

**结论：DDTI 只有 TI-RADS 分级 = B 类，无 A 无 C。不能用于漏诊率。**

### 7. AUL — 名字记错了，而且良恶性两类金标准不同

- 记录标题是 **"Annotated Ultrasound Liver images"**，不是 "Abdominal Ultrasound Lesions"
- 我实际下载并解压三个 zip，**实测图像数**：

| 目录 | 实测图像数 |
|---|---|
| Benign | 200 |
| Malignant | 435 |
| Normal | 100 |
| 合计 | **735** |

每图配 JSON 多边形轮廓（`Benign/segmentation/mass/*.json`，如 `[[430.7,405.6],[426.5,434.4],...]`）。

**标签来源是混合的，必须分开写**——这是本报告里最容易写错的一条：
> "**Malignant masses and FNHs were confirmed by biopsy or post-surgery pathology, whereas hemangiomas and cysts were confirmed by enhanced imaging.**"
> —— 关联论文 Briefings in Bioinformatics 2023, DOI 10.1093/bib/bbac569, PMC10390801

→ **恶性侧 = A 类（病理）；良性侧（血管瘤/囊肿）= B 类（增强影像）**。
注意 FNH 也算 A 类但它不是典型良性对照。**良性侧金标准弱，是这套数据算漏诊率的最大隐患**（因为漏诊率的分母/假阴性恰恰依赖良性标签可信）。

另注：该论文主数据集 50,063 图 / 11,468 例，**Zenodo 只公开 735 张子集**。许可标 CC BY 4.0，但描述里又写 "subject to copyright ... must contact the author"，两者冲突。

### 10. 明确排除的三类"常见误选项"

#### MIMIC 系列 —— **无超声**
- **MIMIC-IV v3.1**（https://physionet.org/content/mimiciv/3.1/）：页面全文 grep `ultrasou*|echocardiogra*|sonograph*` → **0 命中**。内容是 "sourced from two in-hospital database systems: a custom hospital wide EHR and an ICU specific clinical information system"，即结构化表（化验/生命体征/用药），**无任何超声影像**。

## 四、最终结论：公开资源能否支撑漏诊率计算？

### 结论：**能算，但算出来的数只能叫「特定样本上的漏诊率」，不能叫「临床漏诊率」。**

三条硬约束决定了这个措辞：

**约束 1 — 样本严重富集，患病率被系统性扭曲**
| 数据集 | 恶性占比 | 真实筛查人群参考 |
|---|---|---|
| TN5000 | **71.5%**（3574/5000） | 甲状腺结节恶性率约 5–15% |
| ThyUS2Path Batch1 | **63.7%**（383/601，batch1） | 同上 |
| ThyUS2Path Batch2 | **58.5%**（141/241） | 同上 |
| TN-SCUI 2020 | **人为 50/50** | 同上 |

**这对漏诊率的数学影响**：漏诊率本身是条件概率 `P(恶性 | 系统判良性)`，**不受患病率影响**，所以你**可以直接算、可以直接报**。但任何派生指标（NPV、总体准确率、每千人漏诊数、收益/成本）都会被这个 71% 拽偏，**必须禁止外推**。

**约束 2 — 没有 C 类，就没有「真阴性」的第二种来源**
所有可用的 A 类集里，"良性"全部来自**被穿刺/被切除的良性**。这意味着：
- 系统判良性且病理良性 → 可以算**特异度**
- 系统判良性但病理恶性 → 可以算**漏诊率**
- **但**"系统判良性、随访 N 月无变化"这条最贴近真实临床工作流的证据链，**拿不到**

后果：算出来的漏诊率是"在**已进入有创诊断流程**的人群里的漏诊率"，会**系统性低估**真实漏诊率——因为真实场景里被判良性的人**大量根本没做穿刺**，他们才是漏诊的高发区。这一点必须在报告里明确写出来。

**约束 3 — 唯二两个"病理 + 特征"双全的集，一个要许可、一个许可封死**
- Stanford Cine-clip：有 TI-RADS 描述符 + 组织病理，但 `isDownloadAllowed: false`，需签 ODUA
- TN-SCUI：有病理，但"participants will NOT be able to use the dataset images in any other publication or study"

### 最小可行方案（MVP）

**推荐主方案：TN5000（主）+ Stanford Cine-clip（验证）**

**第 1 步（本周可做，零门槛）— 用 TN5000 建立漏诊率基线**
1. 取 TN5000（5000 图，VOC 格式，带 train/val/test split）→ **免申请、可立即下载**
2. 只用**测试集**，且**只报混淆矩阵四格**，不报任何加权指标
3. 核心输出：
   ```
   漏诊率 = FN / (FN + TP)          # 系统判良性中真为恶性的比例
   附：该样本恶性占比 = 71.4%（必须与漏诊率同框出现）
   附：漏诊病例的 TI-RADS 分级分布  # 用来解释"漏在哪"
   ```
4. **同时报 ThyUS2Path 作为独立外部验证**（不同医院、全手术病理、恶性 58–64%）。两个集恶性占比不同（71.5% vs 62.2%），恰好能证明漏诊率对患病率不敏感——这本身就是个有力的稳健性论证。

**第 2 步（需申请，1–2 周）— 补 TI-RADS 维度**
1. 申请 Stanford AIMI 账号，签 ODUA v1.0，取 Thyroid Cine-clip（192 结节 / 167 例）
2. 它带 **TI-RADS 结构化描述符 + 组织病理**，可以算"系统 TI-RADS 分级 vs 病理"的一致性，这是 TN5000 给不了的
3. 规模小（192 结节），**只能做验证集，不能做主集**

**第 3 步（必须做，否则结论站不住）— 明写局限**
报告里必须出现这段：
> 本漏诊率基于**已接受穿刺或手术**的甲状腺结节人群计算，恶性占比 71.5%（TN5000）/ 63.7%（ThyUS2Path），远高于自然人群。未接受有创诊断、仅靠超声随访的结节（真实临床中被判"良性"的主体）**未被纳入**，故该指标为**下界估计**，不可外推为临床漏诊率。

### 如果不能接受"下界估计"——缺的到底是什么

必须直说：**缺的不是影像，是"被判良性之后发生了什么"这个纵向链接。**

具体缺三样，缺一样都做不成真正的 C 类：
1. **同一结节的纵向配对影像**（T0 超声 → T1/T2 超声），且带时间间隔。公开集里**一个都没有**（SegThy 有随访人群但无结局；其余全是横断面）。
2. **"随访 N 月无变化"作为良性参照标准**的书面定义与执行记录（间隔多久算、用什么判"无变化"、谁判的）。目前公开集连这个字段名都不存在。
3. **被判良性人群的转归追踪**（是否后来穿刺/手术/确诊恶性）。这类数据只在**医院内部 PACS + 病理系统 + 随访登记**三库打通后才存在，欧盟/中国均属受控数据，不可能公开。

**唯一的现实解法**（如果不是纯论文导向）：
- 短期：用 TN5000 + ThyUS2Path 出「富集样本漏诊率 + 明确标注为下界估计」，先把指标口径立起来
- 中期：**向合作医院申请自有数据**——需要的字段就三个：`超声报告(含TI-RADS) + 病理结论 + 末次随访日期/状态`。这正是 UK Biobank 那种"申请制"模式的场景，但 UK Biobank 本身**没有甲状腺超声**，不能指望
- 别指望的路径：TCIA（本次连不上，需重验）、MIMIC（无超声）、OpenNeuro（无超声）、Zenodo/Dryad/Figshare 全库检索（零命中）
