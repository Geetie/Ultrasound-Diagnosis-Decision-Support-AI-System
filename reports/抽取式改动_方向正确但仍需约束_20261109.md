## 三、模型的两种「作弊」模式（新发现）

### 模式 1：先下结论，再补一段无关原文

```
「4A 类结节 13mm 且紧邻被膜，需要穿刺。
 原文提到：如果要建立危险分层，821% 的受访医生希望沿用 ACR-BIRADS…」
```

**结构是**：`[结论] + 「原文提到：」+ [随便一段原文]`

模型学会了「答案里必须有『原文提到：』」这个格式要求，
但**内容对不上**。而且 `821%` 这种数字它也能编（原文里没有）。

### 模式 2：「这说明」式推断

```
原文：典型转移性淋巴结需行 FNA。
答案：这说明两套指南并存时可能会导致诊断结果出现矛盾。
```

**原文讲的是 FNA 指征，答案却推到了「指南矛盾」。** 这是模型自己做的因果推断。

## 四、这说明什么

**摘录式方向是对的（三条验证全对），但提示词约束不住「结构」**：

| 我要求的 | 模型做的 |
|---|---|
| 每个字都要在原文里 | 先写自己的结论，再贴一段原文 |
| 不许推断 | 用「这说明」接一段无关原文 |
| 不许补充数值 | 编出 `821%` |

## 五、可以立刻加的硬约束（程序化，不靠提示词）

### 约束 1：答案必须以「原文提到：」开头

```
✅ 「原文提到：4A 类 FNA 阈值 >15mm…」
❌ 「4A 类结节需要穿刺。原文提到：…」    ← 结论在原文之前
```

### 约束 2：「原文提到：」之后的内容必须在原文里逐字存在

用 `__contains__` 检查（比现在只查关键词严格）。

### 约束 3：答案里的每个数值必须在原文里

现有闸 7 已做，但**只查了带单位的数**，`821%` 这种漏了？——抽查时它在答案里，闸 7 应能抓到。
需要验证闸 7 是否真的在跑。

## 六、诚实结论

**这一轮取得的进展**：找到了绕开医学知识不足的方法（摘录式），并在 3 条 L3 抓错案例上验证全对。
