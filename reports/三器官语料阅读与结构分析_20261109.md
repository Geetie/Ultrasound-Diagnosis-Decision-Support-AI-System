## 二、逐字阅读后的结构性判断

### 2.1 C-TIRADS 2021：信息密度极高，但知识库只入了它的「碎片」

这份 16 页文档我读完了，它的结构是：

```
引言（TIRADS 历史、中国为何要自建）
第一部分：超声在甲状腺结节诊治中的作用
  ├ 一、超声的价值         ├ 二、FNA
  ├ 三、PTMC 过度诊治       └ 四、中国现状（5044 份问卷）
第二部分：中国版 TIRADS
  ├ 一、成像质量控制（仪器/扫查/参数）
  │    ├ 灰阶    ├ 彩超（scale 1~5 cm/s）
  │    ├ 弹性    └ 造影（MI < 0.3）
  ├ 二、超声影像学词典（10 类术语，每类带「意义」）
  │    1.位置 2.方位 3.边缘 4.声晕 5.结构
  │    6.回声 7.回声质地 8.局灶性强回声 9.后方回声 10.大小
  │    + 彩色多普勒（5 型血供）+ 弹性（3 型）+ 造影（5 型）
  ├ 三、分类系统与处理建议
  │    ├ 建立过程（131 家医院、2141 例、565 恶性）
  │    ├ **表1 计数法分档表**
  │    ├ 分类注意事项（5 条：医生经验/病史/淋巴结/点状强回声/弹性造影）
  │    ├ 特殊类型病例（6 类：囊性/白骑士/结节性甲肿/钙化遮挡/暴风雪/弥漫微钙化）
  │    ├ **处理建议（TIRADS 1~6 类逐档 + FNA 阈值）**
  │    └ 报告系统（用哪 5 类术语、随访 6~24 月）
  └ 推荐条款 1~16（带 A/B/C/Ⅰ 证据等级）
```

**这份文档的价值点，我逐条标了「知识库里有没有」**：

| 内容 | 知识库有吗 | 重要度 |
|---|---|---|
| 表 1 计数法分档表 | ❌ **曾被切碎丢失**（我手工补了） | ★★★★★ |
| 10 类术语定义 + 「意义」 | ⚠️ 部分有，但「意义」段常被切成孤立块 | ★★★★★ |
| 5 型血供分类 | ⚠️ 有，但缺"意义"（结论不一） | ★★★ |
| 3 型弹性分型 | ❌ 缺（原文明确说「暂不纳入分层」） | ★★ |
| 5 型造影分型 | ❌ 缺 | ★★★ |
| **6 类特殊病例处理**（白骑士/暴风雪/钙化遮挡…） | ⚠️ 有但散 | ★★★★★ |
| **逐档处理建议 + FNA 阈值** | ⚠️ 有但常与"恶性率"分离 | ★★★★★ |
| 分类注意事项 5 条 | ⚠️ 部分 | ★★★★ |
| 推荐条款 1~16 + 证据等级 | ❌ 基本没有 | ★★★ |

**关键发现**：这份文档的**最强价值在「处理建议」和「特殊病例」两节**——医生最常问的就是"这个 4A 类 12mm 要不要穿"，答案在这一节。但这两节在分块时被 SentenceBoundaryChunker 按句子切成了碎片，**"4A 类"和"> 15mm 建议 FNA"很可能不在同一个 chunk 里**。

### 2.2 甲状腺癌诊疗规范 2018：与 C-TIRADS 有**实质冲突**（重要）

我读超声章节时发现一个**必须处理的口径冲突**：

| 项 | C-TIRADS 2021 | 诊疗规范 2018 |
|---|---|---|
| 4a 恶性风险 | **2%~10%** | **5%~10%** |
| 4b | 10%~50% | 10%~50% |
| 4c | 50%~90% | 50%~85% |
| 5 类 | **>90%** | **85%~100%** |
| 3 类 | **<2%** | **<5%** |
| 分类体系 | **计数法**（积几分） | **征象数法**（几种恶性征象） |
| FNA 阈值（4A） | >15mm | **>1cm（=10mm）** |
| FNA 阈值（4B） | >10mm | 未单独区分 |
| "极重度"分层 | 无 | 无 |

**这是两个不同的体系，风险区间不一致、FNA 阈值差 5mm。**

**对本系统的影响**：
- 如果检索同时命中两份，模型可能引用 2018 的">1cm"和 2021 的"4a 类 >15mm" → **给出互相矛盾的穿刺建议**
- B2 检索集里 `zh-ret-013` 就是在问「2022 版指南 4c 和 C-TIRADS 的 4C 是不是一个口径」——**说明这个冲突是真实的临床疑问**

**这一条我认为是当前语料结构最大的风险**，比表格切碎更严重：切碎导致"查不到"，冲突导致"查到两个答案"。

### 2.3 CEUS LI-RADS v2027：质量最高的文档，但**可能用错了场景**

这份 39 页的文档质量极高：

```
第 3 页：CEUS Diagnostic Table（APHE × 大小 × 洗脱类型 → LR-3/4/5）
        + LR-M 四条标准（rim APHE 伴洗脱 / <60s 洗脱 / <2min 显著洗脱 / <2min 显著低增强）
        + LR-TIV / LR-NC / LR-2 / LR-1 / LR-3 / LR-4 / LR-5 / LR-M 全档定义
第 8 页：v2027 的 7 项更新（含为什么改）
第 9 页：新增 AF（KCA 5min 无低增强但 ≥10min 出现）
第 17 页：血管时相（动脉 10-40s / BPA 门脉 30s-2min / 晚期到 6-8min；
          KCA 过渡相 1-5min 早期、5-10min 晚期、Kupffer 相 ≥10min）
第 18 页：技术参数（低机械指数、双屏、20G 以上留置针、2-3s 手推 + 5-10mL 冲管）
```

**但我注意到一个关键限制（原文第 6 页写明）**：
> "CEUS **does not depict capsule**; therefore, it is **not a CEUS major feature**."
> "CEUS permits characterization of **limited number** of nodules and **cannot fully assess extrahepatic disease**; hence, it **may not be suitable for HCC staging**."

**这是 CT/MRI LI-RADS 与 CEUS LI-RADS 的核心差异**：
- CT/MRI 的 LR-5 判据**包含包膜（capsule）**，CEUS 没有
- 所以**两套 LR-5 判据不能混用**

**风险**：知识库里同时有 CT/MRI LI-RADS v2018 和 CEUS LI-RADS v2017/v2027。
如果模型检索到"LR-5 判据：APHE + 洗脱 + **包膜** + 阈值增长"，而用户问的是**超声造影**场景，
模型会把 CT/MRI 的判据套到 CEUS 上 → **给出技术上错误的判读**。

**这是第二个"查到错误答案"的风险。**

### 2.4 心脏语料：版本最杂，有 4 份"同名不同版"的舒张功能指南

| 文件 | 年份 | 关系 |
|---|---|---|
| `ase_diastolic_2025.pdf` | 2025 | **ASE 最新** |
| `bse_diastolic_2024.pdf` | 2024 | BSE（英国），与 ASE 口径**可能不同** |
| `cardiac_valve_consensus_2021.pdf` | 2021 | 中国瓣膜共识 |
| `ase_strain_2025.pdf` | 2025 | GLS |

**舒张功能分级（Grade 1/2/3）这件事，ASE 2025 和 BSE 2024 可能有不同切点。**
两份都入库后，模型可能给出"E/e' > 14 是 Grade 2"（ASE）和"E/e' > 13 是 Grade 2"（BSE）两个答案。

**这是第三个"同题多答案"风险。**

## 三、「够不够」的判断

### 3.1 数量：**够了**

| 器官 | 权威来源 | 覆盖度 |
|---|---|---|
| 甲状腺 | 中国指南 2 份 + ATA 3 份 + 韩国 1 份 | **充分** |
| 肝脏 | 中国 2 份 + ACR 4 份 + CT/MRI LI-RADS | **充分** |
| 心脏 | 中国 3 份 + ASE 6 份 + BSE 1 份 + JAHA 1 份 | **充分** |

**从"有没有权威依据"看，三器官都已经覆盖到国际+国内双轨。**

### 3.2 但**结构上有三个真实问题**，每一个都比"缺语料"更危险

| # | 问题 | 后果 | 严重度 |
|---|---|---|---|
| **1** | **甲状腺两套体系冲突**（C-TIRADS 计数法 vs 诊疗规范 征象数法，4a 风险 2-10% vs 5-10%，FNA 阈值 15mm vs 10mm） | 模型可能同时引用两个 → **给出互相矛盾的穿刺建议** | ★★★★★ |
| **2** | **CT/MRI LI-RADS 与 CEUS LI-RADS 不能混用**（CEUS 无包膜、不能分期） | 模型可能把 CT/MRI 的 LR-5 判据套到超声造影 | ★★★★★ |
| **3** | **心脏舒张功能 ASE 2025 vs BSE 2024 切点可能不同** | 同题两个答案 | ★★★★ |
| 4 | 表格被分块切碎（表1 分档表、参考值表） | 查不到 | ★★★（我已手工补了一张） |

### 3.3 我的结论

**语料"够"了，但"没有组织好"——缺的不是更多语料，是「同一问题的多个权威口径如何共存」的机制。**

具体建议（按优先级）：

| 优先级 | 做什么 | 为什么 |
|---|---|---|
| **P0** | **给每份语料打「适用场景」标签**：`C-TIRADS-2021` / `诊疗规范-2018` / `CEUS-LI-RADS-v2027` / `CTMRI-LI-RADS-v2018` | 检索时先按场景过滤，避免混用 |
| **P0** | **冲突条目显式并列**：把"4a 类恶性风险"做成一条知识，内容是「C-TIRADS 2021: 2-10%；诊疗规范 2018: 5-10%」 | 让模型看到冲突，而不是随机取一个 |
| **P1** | 分块器加**表格保护**（表N / Table N / 连续 `|` 行不切） | 根治表格碎片化 |
| **P1** | 分块器加**适用场景元数据**（从文件名/标题推断） | 支撑 P0 |
| **P2** | 补 CEUS LI-RADS v2017 的差异说明（v2027 已替代它） | 避免引用过时版本 |

## 四、我读完后对「语料质量」的正面评价

**这三批语料的质量是高的**，理由：

1. **都是原始指南，不是二手科普**。CTA/TIRADS 来自中华医学会，LI-RADS 来自 ACR，ASE 来自美国超声心动图学会。
2. **版本新**：ASE 舒张功能 2025、ASE 右心 2025、ASE 应变 2025、CEUS LI-RADS **2027**（比当前年份还新，说明是很近的版本）。
3. **中英文都有**：ASE 有两份**官方中文译本**（负荷超声、综合 TTE），这对中文检索是实质利好。
4. **内容深度够**：C-TIRADS 有「表1 分档表 + 逐档处理建议 + 6 类特殊病例」，CEUS LI-RADS 有「完整诊断表 + 血管时相 + 技术参数 + 7 项 v2027 更新理由」。这些足够支撑临床决策。

**所以问题不在语料，在语料的"可检索性"和"场景隔离"。**
