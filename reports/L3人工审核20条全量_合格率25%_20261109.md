## 三、19 条不合格的**六大类问题**（按出现频次）

### 类别 1：query 是骨架照抄或拒答模板（7 条）

```
「这份原文能回答甲状腺的问题吗？」           ← 我给的拒答出口
「如果医生按原文提到：的分级标准，质控该如何处理？」 ← 清理残句
「报告写 GLS，我作为心脏超声医生应该怎么做？这份原文能回答心脏的问题吗？」 ← 两句拼接
```

**根因**：我在 prompt 里给了「如果原文主体讲别的器官就写 answerable: false」这条出路，
模型把它当成了一条正常出题路径，大量产出这种垃圾。

### 类别 2：书名号清理产生残句与重复（5 条）

```
「原文提到：和原文提到：的分类标准」
「统一使用原文提到：或原文提到：中的标准」
```

**这是我的 bug**：`_strip_fake_citations` 把多个《X》各替换成「原文提到：」，
拼在一起就成了「原文提到：和原文提到：」。

### 类别 3：医学错误（4 条，最严重）

| 条目 | 错误 | 真相 |
|---|---|---|
| 005 | 4A 类 → 「TR4 级」 | 4A 低度可疑 / TR4 中度可疑，**差一档** |
| 012 | 1.5cm 边界清晰 → 「TR2 级，积分 3 分」 | TR2 是 1 分（无恶性征象），**分级与积分都对不上** |
| 014 | 「13 分结节」 | C-TIRADS 满分 5 分，**13 分不存在** |
| 020 | LR-3 → 「明确恶性」 | LR-3 是「可能良性或低度恶性」，**LR-5 才是明确恶性** |

**这四条如果进数据集，测出来的「检索能力」毫无意义** —— 因为标准答案本身是错的。

### 类别 4：编造版本号（2 条）

```
「LI-RADS v2027」← 当前最新是 v2017，2027 是编的
```

我的闸 1 只查《书名号》，查不到这种**不带书名号的编造**。

### 类别 5：query 自相矛盾或不可能（3 条）

```
「甲状腺结节大小 1.2cm，直径小于 1.0cm」    ← 不可能
「18FDG-PET 阳性，我作为超声科住院医师要不要安排手术」 ← PET 不是超声科的事
```

## 四、这轮最重要的结论

**L2 合成集的真实合格率是 5-25%（n=20 时 5%）。**

之前报的「过闸率 48-63%」是**严重虚高** —— 因为 12 道自动闸检查的是
「字面特征」，而**医学正确性无法用正则检查**。

## 五、必须做的一个决定

**这个合成链路要不要继续？**

| 选项 | 依据 |
|---|---|
| **A. 停止 L2，改用 L1+L3** | 合格率 5%，投入产出比极低 |
| **B. 修复六大类问题再试一轮** | 问题都是可定位的（拒答模板、清理bug、医学错误） |
| **C. 换生成模型（GPT-4o-mini）** | 8B 模型的医学知识不足是根本原因 |

**我的判断**：
- 类别 1/2/5/6 是**工程 bug，可修**（拒答模板去掉、清理逻辑改对、query 自洽检查）
- 类别 3（医学错误）**修不了** —— 8B 模型不知道 C-TIRADS 满分是 5 分，
  也不知道 LR-3 不是「明确恶性」。**这是知识问题，不是提示词问题。**

**所以：先修工程 bug（1-2 轮），若医学错误仍占主导，就必须换模型或停 L2。**
