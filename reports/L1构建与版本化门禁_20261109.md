## 一、L1 构建完成，但发现源数据几乎是空的

### 1.1 构建结果（`p124_build_l1_replay.py`）

从 `diagnosis_results.clinical_text` 提取：

```
DB 里长度≥20 的文本: 661
分类：
  fake（自造演练/冒烟）       110  ← 剔除
  ask（含提问）               135
  report（陈述式）            419
语言：
  en                          293  ← **剔除**（早期测试样本，非真实使用场景）
  zh                          155
  mixed                       106
```

**纯英文剔除理由**：293 条全部是 `Within the thyroid gland, a nodule is identified...`
这类英文报告，来自 09-29~10-01 的链路测试。用它们检索中英混排知识库，
top-1 抓到的是零碎英文片段（`resources/guidelines/thyroid.pdf). Thyroid US can answer...`）。
**这不是重排问题，是语言不匹配。**

### 1.2 但去重后只剩 25 条唯一

```
ask 类 135 条 → 唯一原文 6 条
report 类 126 条 → 唯一原文 19 条（thyroid 17 / cardiac 2 / liver 2）

重复 top：
  ×102  「甲状腺超声检查，请结合影像给出 TI-RADS 分级。」
  ×44   「右叶低回声结节，边界清…8x6mm」
  ×28   「左叶混合回声结节…12x9mm」
```

**重复率 99%。** `diagnosis_results` 里的 661 条"真实数据"本质是测试工具反复提交的那几句话。

### 1.3 这对三层方案的影响

| 层 | 计划 | 实际 |
|---|---|---|
| L1 生产回放 | 全量真实文本 | ❌ **只有 25 条唯一** |
| L2 受控合成 | 覆盖矩阵 480 条 | ⚠️ 产能已解决（过闸 63%） |
| L3 人工精标 | 50-100 条 | 可做 |

**L1 无法作为"真实场景评测集"。** 这个结论必须如实记录。

## 二、版本化与覆盖矩阵检查（`p126_dataset_version.py`）

### 2.1 解决交付项 5（指标必须可追溯）

每份数据集旁挂 `manifest`：

```json
{
  "dataset_version": "rag-eval-v1.0.0",
  "fingerprint": "05d9fd164104d42d",     // 内容指纹（sha256 of sorted queries）
  "git_commit": "2819963",
  "n": 44,
  "distribution": {"hop": {...}, "specificity": {...}, "persona": {...}, "length": {...}},
  "coverage_cells": 33,
  "cells_below_min": 0
}
```

**指纹只标识「这批问题」，不含 answer/gold** —— 标注修订不应改变数据集身份。

### 2.2 覆盖矩阵实测（H60 的 44 条）

```
理论格子数: 48（hop × spec × persona × length）
实际有样本: 33
⚠️ 缺 metadata 维度: {hop: 7, specificity: 7, persona: 7, length: 7}  ← 被拒条目
```

**33/48 格有样本**，其余 15 格因场景池不足未覆盖。

## 三、进 CI（交付项 6）

`.github/workflows/ci.yml` 的 `rag-eval-gate` job 加：

```yaml
- name: Synthetic data gate + dataset version guards (p121/p126)
  run: |
    python -m pytest tests/unit/quality/test_p121_synth_gate.py \
                     tests/unit/quality/test_p126_dataset_version.py
```

**为什么守护而不是跑本体**：p121 要调 LLM、p126 要连 DB，CI 跑不了。
但**判据与阈值必须被守护** —— 2026-11-09 实测：8B 模型在提示词明确写
「禁止编造文献名」时仍有 4/10 编造，若有人把闸放宽，数据集会静默退化。

### 新增 16 个测试（全绿）

| 测试类 | 守护什么 |
|---|---|
| `TestThresholds` | MIN_ANSWER=40 / MAX_QUERY=80 不被放宽 |
| `TestFabricatedCitationDetection` | 《C-TIRADS 2018》这类编造必须被抓；真实书名不误报 |
| `TestCrossSystemDetection` | 甲状腺+LI-RADS / 肝脏+C-TIRADS 必须抓 |
| `TestQueryShape` | 陈述式 query 必须抓；好问题零告警通过 |
| `TestFingerprint` | 同内容同指纹、异内容异指纹、标注修订不改指纹 |
| `TestCoverage` | 四维度计数、嵌套 metadata 兼容、缺维上报 |
