# 三条任务完成报告（2026-11-08）

## 任务 1：T2b 重训 —— ✅ 达标且经独立复算

### 真实根因：p87 的 20.99% 是**代码 bug**，不是"微调毁特征"

四处独立缺陷，**四处都有实测证据**：

| # | 缺陷 | 证据 |
|---|---|---|
| ③ | **标签-特征错位**（最致命） | p87 抽特征用 `shuffle=True` 但按 CSV 原序配标签。**我独立复现：错位率 79.77%（16120/20207）**，Agent 两次复现 78.7%~78.9% |
| ② | 训练用了验证集变换（零增强） | `create_model_and_transforms()` 返回 `(model, preprocess_train, preprocess_val)`，写成 `model, _, preprocess` → 训练实际用 preprocess_val |
| ① | 样本内打分 | `eval_split` 同一份特征 `fit` 再 `predict` |
| ④ | 对比损失正样本口径错 | `ClipLoss` 批内对角线，但 batch=256 只有 5 条 caption，理论下界 log(51.2)=3.94，实测 4.03~4.21 贴地走不动 |

**消融定位**：只修③、其余照抄 p87 原配方 → 0.2099 → **0.9122 → 0.9180**。
→ **0.2099 的唯一主因是③，①②④是真实缺陷但量级远小。**

## 任务 2：甲状腺跨器官迁移 —— ✅ **假设成立**

### 四条 lane 对照（同一 test 子集 n=1001）

| lane | AUC | 95% CI |
|---|---|---|
| ① 现网 T2a（零训练） | **0.6241** | [.5839, .6666] |
| ② 冻结 BiomedCLIP + LR | 0.7963 | [.7651, .8266] |
| 冻结 zero-shot 文本 | 0.6362 | [.5969, .6752] |
| ④ **重训视觉塔** | **0.9122** | [.8918, .9313] |

### 同口径复现检查（我方独立核实）

```
p90 全量 5000 例 AUC: 0.6303
p93 子集 1001 例 AUC: 0.6241
差值: 0.0062（子集抽样导致，<0.05 属噪声）
```
→ **同口径复现成立**，两条独立路径给出同一个 baseline。

### 结论

**跨器官迁移失败假设成立**：现网 T2a 在肝脏 AUL 上 AUC 0.8950，到甲状腺掉到 0.6303；
用甲状腺数据重训视觉塔后升到 **0.9122**，**已接近其肝脏水平**。
→ 瓶颈是**视觉塔的肝脏域偏差**，换域重训即可修复，**不是任务本身不可分**。

### 附带发现：连冻结特征都比现网好

「② 冻结 BiomedCLIP + LR」= 0.7963，比现网 0.6241 高 **17.2pt**，
说明**连不做任何微调的通用特征都比现在这个肝脏微调过的塔更适合甲状腺**。

### 补充严谨性（Agent 主动做的）

- **划分敏感性**：换 5 个 seed 重跑冻结探针 → 0.7856~0.7993（std **0.0058**），结论不依赖划分
- **欠拟合排除**：加跑到 20 epoch，第 6 轮达峰后第 10 轮早停，**结果完全一致 0.9122**
- **限制**：TN5000 **无患者 ID**，只能图像级随机划分，同一患者不同切面可能跨 train/test → **AUC 偏乐观**，不能当注册申报级独立验证
