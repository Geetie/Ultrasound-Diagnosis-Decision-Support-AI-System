## 填写规则（先读）

1. **`⏳ 待测` = 数据就绪但还没跑；`⛔ 阻塞` = 缺前置条件（写明缺什么）；`✅ 已测` = 有脚本 + n + CI。**
2. **不许填"约""左右""大概"**——必须是实测数字或留空。
3. **每个数字必须能溯源**：`{脚本路径} + {report json} + n + CI`。
4. **作废口径永久禁填**：hit@10=98.53% / 一致率 79.56% / faithfulness 0.935 等 7 项（见 A.166）。
5. **受污染数字必须标 ⚠️ 并写明污染来源**（如 CACTUS 官方 test.csv）。
