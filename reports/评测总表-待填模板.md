## 填写规则（先读）

1. **`⏳ 待测` = 数据就绪但还没跑；`⛔ 阻塞` = 缺前置条件（写明缺什么）；`✅ 已测` = 有脚本 + n + CI。**
2. **不许填"约""左右""大概"**——必须是实测数字或留空。
3. **每个数字必须能溯源**：`{脚本路径} + {report json} + n + CI`。
4. **作废口径永久禁填**：hit@10=98.53% / 一致率 79.56% / faithfulness 0.935 等 7 项（见 A.166）。
5. **受污染数字必须标 ⚠️ 并写明污染来源**（如 CACTUS 官方 test.csv）。

> ### ⚠️ 泄漏核实（2026-11-08，用户质疑后查清）
>
> **CACTUS 官方 train/val/test 三个 CSV 共享 117 个视频**（`train∩test 视频 = 110`）。
> 官方按**图像**随机切 → 用官方 train.csv 训练的模型，在任何官方 test 上测都是**帧级泄漏**。
> 实测「test+val 中视频从未在 train 出现」的图 = **0 张**。
>
> 因此：
> - p86 的 0.9786 ❌ 作废（帧级泄漏）
> - 我此前报的 97.43% ❌ 作废（错把 `video_disjoint_split` 的 test 用于测「已在 train.csv 上训练」的权重，
>   路径重叠 **3160/4511 = 70.05%**、视频重叠 **17/17**）
> - **只有 p92 的视频不交集重训是干净的**：train∩test 视频 **0**、路径 **0**，test 占 15.7%
>
> 但 p92 的 test 只有 **17 个视频** → 视频级 CI [0.8278, 0.9959] 很宽，
> **不能声称 0.9215 有 ±1% 精度**。
>
> **1.11 已达标且经独立复算**（2026-11-08）：
> p92 配方 `full_lr3e6`（lr=3e-6，全视觉塔可训，CE 类别锚点损失，官方 preprocess_train 增强，早停）
> → **test acc 0.9031**，超冻结基线 0.8628 **+3.9pt**，远超目标 0.80。
> **我另写 p95 做独立复算**（只推理不训练、强制 `shuffle=False`、断言 `order==range(n)`），
> 复算得 **0.9031 / 宏F1 0.9054**，与 p92 完全吻合 → 数字可信。

### 1.19 跨器官迁移结论（p93，2026-11-08）

**假设成立**：现网 T2a 在肝脏 AUL 上 AUC **0.8950**，到甲状腺掉到 **0.6303**；
用甲状腺数据重训视觉塔后升到 **0.9122**，已接近肝脏水平。
→ 瓶颈是**视觉塔的肝脏域偏差**，换域重训即可修复，**不是任务不可分**。

**附带发现**：连「冻结 BiomedCLIP + LR」（0.7963）都比现网（0.6241）高 **17.2pt**，
说明不做任何微调的通用特征都比这个肝脏微调过的塔更适合甲状腺。

**限制**：TN5000 无患者 ID，图像级划分 → **AUC 偏乐观**，不能当注册申报级独立验证。
