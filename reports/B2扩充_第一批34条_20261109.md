## 四、发现并修掉 p79 门禁自身的一个缺陷

### 症状
首批 34 条写完后跑 p79：`imaging_term_coverage = 0.4351` **FAIL**（阈值 0.50）。

### 根因
**p79 的 `IMAGING_TERMS` 表只有 35 个词，且全是 ACR 那套英文码**：

```
原文只收：TI-RADS / LI-RADS / TR1-5 / 低回声 / 纵横比 / 微钙化 …
完全没有：C-TIRADS / 4A / 4B / 4C / FNA / LVEF / E/e' / 舒张功能 …
```

我写的 query 用的是 `C-TIRADS`（中国体系）、`4A 类`（中文分类码）、
`FNA`、`LVEF`——**这些全是标准影像术语，只是原表没收录**。

### 危害
若不修表，会**逼着写条目的人往 query 里硬塞 `低回声` 这类词来"骗过门禁"**
→ 反而让数据集模板化，与这道闸的初衷（测真实能力）相反。

### 修法
把术语表从 35 个扩到 **85+ 个**，按 7 类组织：
分级体系（含 C-TIRADS/4A-4C/LR-1~LR-M）、回声性质、形态边界、
检查手段、结构描述、操作测量、**心脏超声（原表完全没有）**。

### 两处刻意的取舍
1. **不收裸的「结节」**：患者问诊也说「甲状腺结节怎么治」，收进来会让指标失去区分力
   （实测会打掉 p79 自己的 `test_imaging_coverage_separates_medical_from_patient_questions`）
2. **只收"医生在超声报告/申请单上真会写的词"**，不收泛化医学词（「疾病」「患者」）

### 效果
```
imaging_term_coverage: 0.4351 → 0.7662   （阈值 0.50，PASS）
p79 自己的 17 个单测全绿
```
