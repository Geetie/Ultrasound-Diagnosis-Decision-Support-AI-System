# 合成产能瓶颈定位：不是关系池，是 LLM 生成多样性

> 日期：2026-11-09｜目标第二轮：解决去重丢弃 53% 的问题

## 一、我的假设（错了一半）

上一轮我判断：去重丢弃 53% 是因为**知识图关系池太小**（234 条，且大量同对重复）。

## 二、扩池做了，但没解决

### 扩池结果（p118 修改）

按 `(grade, organ, src_a, src_b)` 四元组分组，组内取全部节点（原先是前 3），
并用 `seen_pairs` 全局去重：

| 关系 | 扩前 | **扩后** | 唯一性 |
|---|---|---|---|
| `cross_source_same_grade` | 234 | **1331** | **100%** |
| `same_grade` | 139 | 172 | 100% |
| `cross_source_same_threshold` | 309 | 309 | 94% |

**关系池扩大 5.7 倍，且全部唯一。**

### 但去重丢弃没降

| 臂 | 关系池 | 过闸 | 去重丢 | 丢弃率 |
|---|---|---|---|---|
| F | 234 | 12 | 16 | **53%** |
| G | **1331** | 13 | **14** | **47%** |

**只降了 6pt。** 扩池基本无效。

## 三、真正的根因（实测证据）

检查 G 臂过闸的 13 条的**节点对**：

```
sc-0821 nodes=2 dup=False
sc-0801 nodes=2 dup=False
sc-0781 nodes=2 dup=False
...（13 条全部 dup=False）
```

**节点对完全没有重复。** 但它们的 query 是：

```
这个 5 分结节按两套指南分别归哪一类？该听谁的？
肝内结节 13mm 且紧邻被膜，要不要穿刺？
肝脏结节 13mm，紧邻被膜，要不要穿刺？   ← 和上一条几乎一样
报告写 CEUS LR-M，我作为超声科主治医师，该不该安排手术？
报告写 CEUS LR-3，我作为外科医生该不该安排手术？  ← 和上一条同构
本院采用的 CEUS LR-M 标准与 LI-RADS v2017 标准对肝脏结节的分级有何冲突？
本院应采用哪套指南，两套指南对肝脏结节分级标准不一致，如何统一标准？  ← 同构
```

**不同的节点对 → 几乎相同的问法。**

## 四、这是 LLM 生成多样性不足，不是工程缺陷

**机理**：我给模型的 prompt 模板固定了「persona + 意图 + 长度」三段，
模型在这个框里只能产出结构相同的问题。

**证据**：
- 节点对 100% 不重复（排除数据重复）
- query 高度同构（同 persona 下的问法骨架一样）
- 还出现了**英文输出**（`CEUS LR-3 nodules with interval size stability for`）——
  说明模型在模板约束下开始"跑偏"

## 五、三条出路（都可能，但成本不同）

| 路 | 做法 | 预期 | 成本 |
|---|---|---|---|
| **A. 提高采样温度** | temperature 0.3 → 0.8-1.0 | 多样性↑，但幻觉↑（闸会拒更多） | 一次实验 |
| **B. 把「问法骨架」也随机化** | prompt 里给 5-8 种问法模板随机选，而非固定三段式 | 多样性↑，可控 | 改代码 |
| **C. 接受低合格率，扩大生成量** | 需要 2100 场景 → 实际要 4200 | 时间成本线性增长 | 最笨但确定 |

**我倾向先试 B（可控），再试 A（如果 B 不够）。**

## 六、诚实结论

**方法论走通了，但产能还差 3 倍。** 而且我上一轮的归因（关系池太小）是错的 ——
扩池 5.7 倍只带来 6pt 改善。

**真正瓶颈：LLM 在固定 prompt 模板下的生成多样性不足。**

这不是"再多试几次"能解决的，需要**改变 prompt 的问法结构本身**。
