# 新增闸 8/闸 9：复检发现此前「过闸」的条目里 21.6% 仍有问题

> 日期：2026-11-09｜目标第 6 轮

## 一、这一轮做的是「用人工视角复检自动闸」

用 L3 评审表的视角扫了一遍 H60 的 37 条过闸条目，发现两类此前漏网的问题。

### 问题 1：query 没有具体锚点（5/37）

```
「边界情况：指南在这条上有没有例外或有争议的地方？」
「什么情况下这条不适用」
「报告这个分级意味着什么、严不严重？」
```

**没说是哪个分级、哪条规则、哪个部位。** 医生不会这样问，
因为它**不含任何可检索的信息**。

**根因**：模型把「问法骨架」直接当成了问题，没填入原文内容。
（这是我上一轮加骨架池的副作用 —— 骨架解决了多样性，但模型学会了照抄骨架。）

### 问题 2：书名号清理留下的残句（1 条可见）

```
「如果医生按原文提到：的分级标准，质控该如何处理？」
```

我的 `_strip_fake_citations` 把「按《LI-RADS 2017》」清成「按原文提到：」，
后面直接接「的分级标准」，句子碎了。

**这是我自己引入的 bug**，不是模型的问题。

## 二、加闸

### 闸 8：query 必须含具体锚点

```python
_ANCHOR_RE = (
    re.compile(r"(?:C-?TIRADS|TI-?RADS|LI-?RADS|LR-?[1-5M]|TR\s?[1-5]|[1-6]\s*[A-C]?\s*类)", re.I),
    re.compile(r"\d+(?:\.\d+)?\s*(?:mm|cm|%|个月|周|岁)", re.I),
    re.compile(r"甲状腺|肝|心脏|左室|右室|二尖瓣|三尖瓣|主动脉瓣|被膜|结节|门静脉|室间隔|瓣环"),
)
if q and not any(p.search(q) for p in _ANCHOR_RE):
    probs.append("query 无具体锚点（没说是哪个分级/数值/部位，医生不会这样问）")
```

### 闸 9：书名号清理的残句

```python
if re.search(r"原文提到[：:]\s*(?:的|是|中|里|[，。；、])", q or ""):
    probs.append("书名号清理后语句破碎（「原文提到：的分级标准」）")
```

## 三、复检结果（同时修正了统计口径）

### 3.1 统计口径也有 bug（我引入的）

原来 p121 只滤 `error`，但 p122 输出里有 `rejected: true` 的条目 ——
它们结构不同（只有 scenario_id + reason，没有 query/answer），
进闸会报「query 为空 / 答案过短 / gold 为空」，
把真实通过率**稀释**了：

```
修正前：44 条里 15 条不合规 = 34.1%   ← 其中 7 条是被拒条目，不该算
修正后：37 条里 8 条不合规 = 21.6%    ← 只检已过闸的
```

### 3.2 九道闸的完整结果（H60 的 37 条）

| 闸 | 抓到 |
|---|---|
| 闸1 引文真实 | 0 |
| 闸2 体系一致 | 0 |
| **闸3 问句形态** | **5** |
| **闸4 答案信息量** | **3** |
| 闸5 gold 一致 | 0 |
| **总不合规** | **8/37 = 21.6%** |

## 四、这意味着什么（重要）

**此前报的「过闸率 63%」是虚高的。**

真实情况：
```
60 条场景 → 37 条通过旧七道闸 → 其中 8 条实际不合格
→ 真实合格 = 29 条
→ 真实过闸率 = 29/60 = 48.3%（不是 63.3%）
```

**但这不全是坏消息** —— 说明闸在持续收紧、抓到的都是真问题。
**21.6% 的复检不合格率，就是「自动闸比人工标准松」的量化差距。**

## 五、对 L3 的意义

L3 人工精标的作用现在更清楚了：

**L3 不是可有可无的抽检，它是校准自动闸的标尺。**

自动闸抓不到的 21.6%，正是 L3 要量出来的。如果 L3 显示人工判定比自动闸严 20pt，
那自动闸的「通过率」必须打个 0.8 折才能对外报。
