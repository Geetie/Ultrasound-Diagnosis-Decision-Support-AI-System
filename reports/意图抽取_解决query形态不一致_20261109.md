# 意图抽取：解决「B2 短问句 vs 生产长描述」的形态不一致

> 日期：2026-11-09｜用户问「你拿去测的问题是医生通过系统会发出的问题吗？」
> 答：不是。本文记录为此做的修复

## 一、问题的量化

| | 长度 | 形态 |
|---|---|---|
| **B2 测试集** | P50 **26 字** | 纯问句：「2022 版指南 4c 类的恶性风险区间是多少？」 |
| **生产实际**（`diagnosis_pipeline.py:907`） | **58-77 字** | 影像描述 + 分级 + 问句混合 |

实测后果：4 条真实描述直接检索，**top-1 全部未命中该问题的答案**。

**原因**：长描述里大部分词是影像特征（实性/低回声/边界清），
这些词在知识库到处都有 → 检索被高频词主导，真正意图被稀释。

## 二、做好意图抽取（`app/rag/intent_extract.py`）

**纯规则、不调 LLM**（检索是热路径，加 LLM 会让 P99 翻倍）。

抽三样：分级码（C-TIRADS 4A / TR4 / LR-5 / LVEF 38%）+ 关键测量 + 问句。

### 实测效果

```
77 → 25 字:  12mm TI-RADS 4A 是否需要穿刺活检？
60 → 25 字:  8mm C-TIRADS 4C类 下一步怎么处理？
59 → 23 字:  32mm 考虑 HCC，LI-RADS 分类？
58 → 32 字:  LVEF 38% 52mm 38% 12mm 收缩功能中度降低。
```

### 开发中修掉的 4 个真实 bug

| # | bug | 症状 | 修法 |
|---|---|---|---|
| 1 | 分级码重复 | `C-TIRADS 4C类 TIRADS 4C` 同一码两个写法 | 按归一化 key 去重 |
| 2 | 测量值重复 | `内径 52mm 38% 厚度 12mm 舒张末期内径 52mm…` 越抽越长 | 按「数值+单位」判重 |
| 3 | **切句吃掉问号** | `[。；！？]+` split → 问号消失 → `？` 标记永远匹配不到 → 含问号的句子被判成陈述句 | 改用零宽断言在终止符**之后**切 |
| 4 | 情形2 取首句 | 首句总是影像描述，截断后常与分级码重复 → 守卫退回原文 | 改用**末句**（结论通常在最末） |

## 三、检索 A/B（n=4，仅方向性）

| 器官 | 原描述命中 | 抽取后命中 |
|---|---|---|
| thyroid（4A 12mm 穿刺） | ❌ | ❌ |
| thyroid（4C 8mm 处理） | ✅ | ✅ |
| **liver（LI-RADS 分类）** | ❌ | **✅** |
| **cardiac（LVEF 38% 分级）** | ❌ | **✅** |

**变好 2 / 变差 0 / 不变 2。**

## 四、诚实说明局限

1. **n=4，判不动** —— 只能说"方向为正、无退化"，不是统计结论
2. **第 1 条（4A 类 12mm 要不要穿刺）抽了也没命中** —— 这是真实检索短板，
   不是抽取能解决的（该问题需要命中 C-TIRADS 的 FNA 阈值表）
3. **尚未接入生产链路** —— 目前只是独立模块 + A/B 验证

## 五、下一步（按顺序）

1. **建 B2-real 数据集**（生产形态，60-120 字描述）—— 这是测生产表现的前提
2. 在 B2-real 上测意图抽取的真实收益（n 够才判得动）
3. 若有效 → 接入 `diagnosis_pipeline` 的检索前置步骤
4. 若无效 → 保留模块但不上线（按纪律）
