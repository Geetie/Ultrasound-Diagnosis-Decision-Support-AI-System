## 结论先行（三句话）

1. **B4 是通的。** 已实际下载并核对两个**病理金标准**甲状腺数据集：TN5000（5,000 图，恶 3574 / 良 1426，CC BY 4.0，零门槛）、ThyUS2Path（842 例 / 8,508 图，恶 524 / 良 318，手术病理，CC BY 4.0，零门槛）。漏诊率的核心量 **P(恶性｜系统判良性)** 可直接算。
2. **B1 一半是通的。** 分级规则是**确定性可编码的**（ACR TI-RADS 已有 MIT 许可开源实现；中国 C-TIRADS 2020 有官方指南），所以**不需要医生"重新标分级"，只需要"特征标注"**。带 5 特征 + 分级 + 病理的公开集**存在**（Stanford Cine-clip，192 结节），但**需申请**。
3. **真正堵死的只有一件事**：「**中文**报告文本 + 医生定的**C-TIRADS** 分级」这一对**同源配对**，公开资源确实不存在。这条我没找到，也没找到绕过办法。

**所以原结论「必须医生参与」应改写为**：
> B1 从"要医生标 200 例中文分级"降级为"**要医生做 1 次规则验收（约 2 小时）+ 1 次中英对照抽样（约 50 例）**"；
> B4 从"要临床方提供随访"降级为"**不需要临床方，公开病理集即可出指标，但指标口径必须标注为下界估计**"。

## 三、找到的替代方案 —— 具体可执行路径

### 3.1 B4 路径（**现在就能做，不需要任何人**）

**Step 1（今天）**：下 TN5000
```bash
curl -L -A "Mozilla/5.0" \
  "https://ndownloader.figshare.com/articles/28455641/versions/1" -o tn5000.zip
# 实测：HTTP 200 / 220,927,209 B
# 解压得 TN5000_forReview/{Annotations,JPEGImages,ImageSets}
# Annotations/*.xml 里 <name>1</name>=恶性 3574，<name>0</name>=良性 1426
```
已把标签表固化为 `data/public_sets/TN5000_labels.csv`（5000 行）与 `data/public_sets/ThyUS2Path_labels.csv`（842 行）。

**Step 2（今天）**：下 ThyUS2Path 作外部验证
```bash
curl -L -A "Mozilla/5.0" \
  "https://ndownloader.figshare.com/articles/27021604/versions/1" -o thyus2path.zip
# 实测：HTTP 200 / 1,640,036,355 B
# 解压得 batch1_image.rar + batch2_image.rar（.rar 用 bsdtar 可解）
# batch{1,2}_image_label.csv → patient_name, histo_label（842 例）
```

**Step 3**：算三个数
| 指标 | 定义 | 为什么可信 |
|---|---|---|
| **漏诊率（主指标）** | `P(恶性 \| 系统判良性)` = 系统判良性中真恶性数 / 系统判良性总数 | **条件概率，不随患病率漂移** |
| 漏诊率 95% CI | Wilson 区间 | 样本量足够（1426 良性 / 318 良性） |
| **稳健性** | 两集漏诊率差异 | 两集患病率 71.5% vs 62.2%，若漏诊率接近 → 证明指标稳健 |

**Step 4**：口径声明（必须同框写，否则重演 A.70）
> 本漏诊率基于**已接受穿刺或手术**的甲状腺结节人群计算，恶性占比 71.5%（TN5000）/ 62.2%（ThyUS2Path），远高于自然人群（5–15%）。未接受有创诊断、仅靠超声随访的结节（真实临床中被判"良性"的主体）**未被纳入**，故该指标为**下界估计**，不可外推为临床漏诊率；**NPV、准确率、每千人漏诊数等派生指标禁止外推**。

**精度损失在哪**：真实的临床漏诊高发区是"**被判良性、因此没做穿刺**"的那批人，公开集里 100% 的人都做了穿刺/手术 → 这层选择偏倚无法用公开数据消除。**但方向是保守的**（算出来的是下界），对"证明系统不危险"这个论证目的而言是可接受的。

### 3.2 B1 路径（**分层，前两层现在就能做**）

**Layer 1（今天，0 成本）—— 把"分级"从"医生标"变成"规则算"**
- 采用 `Lightbridge-KS/tirads-calc`（MIT）作为**参考实现**，或按同样逻辑移植到 Python（约 150 行）。
- 这一步把 B1 的需求从「**分级标注**」降级为「**特征标注**」。这是本次调研最有价值的结论：**ACR TI-RADS 是确定性规则，不需要第二个医生来"再判一次"**。

**Layer 2（今天，0 成本）—— 自研 C-TIRADS 计算器**
- 依据 [C-TIRADS 2020 官方指南](https://doi.org/10.1007/s12020-020-02441-y)。
- C-TIRADS 的 5 要素与 ACR 五要素**语义一一对应**，可直接复用 Stanford 的字段：
  | C-TIRADS 要素 | Stanford 字段 |
  |---|---|
  | solid composition | `ti_rads_composition` |
  | microcalcifications | `ti_rads_echogenicfoci`（punctate） |
  | marked hypoechogenicity | `ti_rads_echogenicity`（very-hypo） |
  | irregular/blurred margins or ETE | `ti_rads_margin` |
  | taller-than-wide shape | `ti_rads_shape` |
- C-TIRADS 分档：TR3 / 4A / 4B / 4C / 5 对应恶性风险 2–10% / 10–50% / 50–90% / >90%（据 [10.3389/fendo.2026.1746242](https://doi.org/10.3389/fendo.2026.1746242) 等文献复述）。项目现有 `app/agents/specialist/thyroid.py` 用 TR1–TR5，需加一层 4A/4B/4C 细分映射。

**Layer 3（需申请，周期 2–6 周）—— 拿到唯一"特征+分级+病理"三全的甲状腺集**
- 申请 **Stanford Thyroid Ultrasound Cine-clip**：192 结节，`ti_rads_*` 五特征 + `ti_rads_level` + `histopath_diagnosis` 全齐，**且带 size_x/y/z → 可直接算"是否建议穿刺"**。
- 用途：这是**唯一能真正验收规则引擎**的数据（拿医生定的 `ti_rads_level` 对比规则算出的 level，算一致率）。
- 192 例够不够？—— 做**一致性验证**够（Kappa 的 95% CI 半宽约 ±0.08）；做**训练**不够。**我们要的是验证，不是训练，所以够。**

**Layer 4（需医生，但只需 1 次、约 2 小时）—— 中英对照抽样**
- 取 50 条中文报告（来自 `C-jd-gh/ultrasound-report-nlp`），请医生逐条给 C-TIRADS 分级。
- 用途：这 50 条是**跨语言校准锚点**——用它测"规则引擎在中文报告上的表现 vs 在英文特征上的表现"的落差（Δ），然后把 Δ 作为系统误差项报出去。
- **这一步不能省**，但它从"标 200 例"缩到"标 50 例"，从"1–2 周"缩到"2 小时"。

## 五、最小可行替代（最重要）

### 5.1 B1 —— 能到什么程度

| 层 | 能拿到什么 | 能算什么指标 | 精度损失 | 要等谁 |
|---|---|---|---|---|
| **L1** 规则引擎 | ACR TI-RADS 五特征 → TR1–TR5 + 是否穿刺 | **规则内部一致性**（自检，非准确率） | 0（确定性规则） | **不等** |
| **L2** C-TIRADS 引擎 | 同上，中国标准 | 同上 | 0 | **不等** |
| **L3** Stanford 192 结节（需申请） | 医生定的 `ti_rads_level` | **分级准确率（ACR 口径）**、与医生一致率 Kappa、**建议穿刺准确率** | 样本 192，Kappa 半宽 ±0.08 | 申请周期 2–6 周 |
| **L4** 50 例中文抽样 | 医生定的 C-TIRADS 分级 | **跨语言校准落差 Δ**（英文特征上 vs 中文报告上） | Δ 作为系统误差项扣除 | **医生 2 小时** |
| **L5** 2,457 条中文报告 | 特征抽取成功率 | `系统分级 vs 规则引擎分级` 一致率（**不是准确率**） | 只能当 sanity check；五要素齐全仅 2.0%，可用样本约 421 条 | **不等** |

**明确结论**：
- 「**分级准确率**」这个数字，**能算**，口径是 ACR TI-RADS，数据源 Stanford 192 例（需申请）。**不需要医生重新标注**，只需要医生**已经标好的**那份数据。
- 「**C-TIRADS 分级准确率**」这个数字，**公开资源算不出来**。只能算"中文报告 → 规则引擎 → 分级"的**自洽性**，并附一个由 L4 得到的跨语言落差 Δ。
- **精度损失的最诚实表述**：`ACR 准确率（Stanford 192 例，金标准）` 与 `C-TIRADS 自洽率（中文 421 条，无金标准）` **不能合并成一个数**。对外只能报前者，后者列在附录作为"规则可用性证据"。

### 5.2 B4 —— 能到什么程度

| 层 | 能拿到什么 | 能算什么指标 | 精度损失 | 要等谁 |
|---|---|---|---|---|
| **L1** TN5000 | 5,000 图（恶 3574 / 良 1426），FNA+病理 | **漏诊率 = P(恶性\|判良性)** + Wilson CI | 患病率 71.5%（真实 5–15%）→ **下界估计** | **不等** |
| **L2** ThyUS2Path | 842 例 / 8,508 图（恶 524 / 良 318），手术病理 | 同上，作**外部验证** | 患病率 62.2% → 下界估计 | **不等** |
| **L3** Stanford 192 | 病理 + TI-RADS 维度 | **漏诊率按 TI-RADS 分层**（TR2/TR3 漏了多少） | 样本小 | 申请 |
| **L4** 真·随访结局 | ❌ **拿不到** | 真漏诊率、N 月无变化率 | — | 只有打通 PACS+病理+随访登记 |

**明确结论**：
- 「**漏诊率**」**能算**，而且**现在就能算**，两个独立数据集交叉验证。这正是原结论判死刑的那一项。
- 但必须叫「**特定样本上的漏诊率（下界估计）**」，不能叫「临床漏诊率」。
- 60 秒能说清的对外表述：
  > 系统判良性、病理证实为恶性的比例是 **X%**（NC 95% CI: Y–Z），基于 5,000 例病理确诊结节；另在 842 例独立手术病理队列复现为 **X'%**。两队列恶性占比分别为 71.5% / 62.2%，高于自然人群，故为下界估计；未穿刺人群的转归不在本指标覆盖范围内。

### 5.3 一句话回答"真的没有办法了吗？"

**有办法，而且比原设想轻得多。**

| 原判断 | 实际 |
|---|---|
| B1「必须医生标 ≥200 例中文分级」 | ❌ 不需要。分级是**规则**不是判断。需要的是：①一次规则验收（**医生 2 小时，50 例**）②一份**已公开**的 192 例特征+分级集（**申请，不用等医生**） |
| B4「必须有临床方提供随访」 | ❌ 不需要。**漏诊率是条件概率**，用公开病理集即可算，**零门槛零等待**。缺的只是"被判良性且未穿刺"那部分人的转归——这使指标成为**下界**，但不妨碍它成立 |
