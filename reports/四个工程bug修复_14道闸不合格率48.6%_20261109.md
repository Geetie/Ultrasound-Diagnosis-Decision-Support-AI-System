# 修 4 个工程 bug + 加闸 13/14：不合格率升到 48.6%

> 日期：2026-11-09｜目标第 9 轮：L3 发现的问题逐项修复

## 一、修的四个工程 bug

### bug 1：拒答模板被模型滥用（影响 7/20 条）

**原 prompt**：
```
如果原文主体讲的是别的器官，就写 `answerable: false`
并在 query 里问「这份原文能否回答{器官}的问题」。
```

模型把这条**当成了正常出题路径**，大量产出：
```
「这份原文能回答甲状腺的问题吗？」
「报告写 GLS，我作为心脏超声医生应该怎么做？这份原文能回答心脏的问题吗？」  ← 两句拼接
```

**修法**：改成只输出 `{"skip": true}`，并明确禁止写询问句：
```
如果原文主体讲的是别的器官，就只输出 {"skip": true}（不要编造问题）。
绝对不要写「这份原文能否回答XX的问题」这类询问——那不是医生会问的问题。
```

同时在 p122 里处理 skip：
```python
if obj.get("skip") is True:
    return {"scenario_id": ..., "rejected": True, "reason": "model_skipped_wrong_organ"}
```

### bug 2：书名号清理产生重复与残句（影响 5/20 条）

**原实现**只处理了「原文提到：原文提到：」这种**紧邻**重复，
但实际出现的是带连接词的：
```
「统一使用《A》或《B》中的标准」→「统一使用原文提到：或原文提到：中的标准」
「《A》和《B》的分类标准」      →「原文提到：和原文提到：的分类标准」
```

**修法**：加连接词折叠
```python
_CONJ = r"(?:和|与|或|、|及|以及|跟|同)"
for _ in range(3):
    out = re.sub(rf"原文提到[：:]\s*{_CONJ}\s*原文提到[：:]", "原文提到：", out)
```

### bug 3：折叠后仍留残句（新发现的）

折叠后出现**无主语的残句**：
```
「统一使用中的标准进行分级」   ← 缺宾语
「的分类标准」                 ← 缺主语
「如果医生按的分级标准」       ← 缺宾语
```

**修法**：**不再尝试用正则修复语法**（越救越复杂），改成**直接判不合格让模型重试**。

### bug 4：检查口径把「被拒条目」也算进分母

原 p121 只滤 `error`，但 p122 输出里有 `rejected: true` 的条目 ——
它们没有 query/answer，进闸会报「query 为空/答案过短」，**稀释真实通过率**。

**修法**：只检 `gate_passed: true` 的。

## 二、新增闸 13/14

### 闸 13：清理后残句

```python
_BROKEN = (
    (re.compile(r"使用\s*(?:中|里)的"), "「使用中的」缺宾语"),
    (re.compile(r"(?:和|与|或|、|及)\s*(?:的|中|里)"), "连接词后直接接助词"),
    (re.compile(r"按\s*的"), "「按的」缺宾语"),
    (re.compile(r"^(?:的|是和)"), "句首是助词"),
    ...
)
```

### 闸 14：C-TIRADS 分级与积分必须对得上（**最重要的一道**）

L3 抓到的医学错误：
```
「1.5cm 边界清晰 → TR2 级，积分为 3 分」   ← TR2 是 1 分
「13 分结节」                              ← 满分 5 分
```

**这类错误靠提示词修不了（模型知识不够），但靠规则能查** ——
C-TIRADS 的分数与分级是写死的：

| 分数 | 分级 |
|---|---|
| -1 | 2 类（良性） |
| 0 | 3 类（良性可能） |
| 1 | 4A |
| 2 | 4B |
| 3~4 | 4C |
| 5 | 5 类 |

```python
_SCORE_TO_GRADE = {(-1): "2", 0: "3", 1: "4a", 2: "4b", 3: "4c", 4: "4c", 5: "5"}
if score > 5:
    probs.append(f"C-TIRADS 积分不可能为 {score}（满分 5 分）")
elif got != want:
    probs.append(f"积分与分级不符：{score} 分应为 {want} 类，答案写 {got} 类")
```
