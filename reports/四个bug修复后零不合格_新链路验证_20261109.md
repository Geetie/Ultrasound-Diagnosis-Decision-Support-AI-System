## 二、本轮另外修正的两个判据 bug

### bug A：闸 14 第一版有漏洞（漏掉真实错误）

**原实现**：拿到 `TR2` 这类码时，因为 `got.startswith("tr")` 就跳过比对。

**后果**：L3 抓到的真实错误「1.5cm 边界清晰 → TR2 级，积分为 3 分」**没被抓到**（只有「13 分」被抓）。

**修法**：拆成两步
- **步骤 A**：分数 + TRx 同现 = 体系混用（TRx 是 ACR 体系，不接受 C-TIRADS 的分数）
- **步骤 B**：分数 + C-TIRADS 类码 必须符合对照表

**验证**（4 个用例）：

| 用例 | 结果 |
|---|---|
| 1.5cm → TR2 + 3 分 | ✅ 抓到（体系混用） |
| 13 分 | ✅ 抓到（超满分） |
| 2 分写成 4A | ✅ 抓到（对照表不符，应为 4B） |
| 1 分 → 4A（正确） | ✅ 不误报 |

### bug B：闸 12 的重复判据误报正确答案

**原判据**：`a.count("原文提到") >= 2` → 判为清理残留。

**问题**：**正常答案引用两处不同事实时本来就会写两次**：
```
「原文提到 EF≤35% 是分层点…原文提到该类患者需随访…」
```

**实测**：这条把 `TestQueryShape::test_good_question_passes` 判成红灯。

**修法**：只抓两种真正的残留形态
```python
_DUP_RE = re.compile(r"原文提到[：:]\s*(?:(?:和|与|或|、|及|以及|跟|同)\s*)?原文提到[：:]")
```
