## 多智能体项目 vs 普通软件项目 文件核心差异总结

1. **完全新增的核心文件**（普通项目无）
智能体角色需求、通信协议、协作编排、调度策略、共识机制、权限边界、工具白名单、MAS 专属提示词、集群部署、故障自愈等。

2. **大幅升级的文件**
需求规格书、架构设计、代码规范、测试计划、验收标准，全部从「单模块开发」升级为「多智能体协同开发」。

3. **AI 编程智能体的特殊要求**
必须有**权限边界 \+ 协作规则 \+ MAS 专属提示词**，避免 AI 生成不符合多智能体架构的代码，同时防止多 Agent 并行开发产生冲突。
