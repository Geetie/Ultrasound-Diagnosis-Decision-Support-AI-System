## 约定

- **一期 MVP**：所有文档默认描述一期 MVP 范围，除非明确标注"二期"或"远期"
- **交叉引用**：跨文档引用优先使用标题锚点格式 `[文档名](文档名.md#section-title-anchor)`（如 `[01-系统架构设计](01-系统架构设计.md#multimodal-preprocessing-layer)`），避免使用章节号（如 X.Y 节），防止章节编号变更导致引用失效。**CI 校验**：须建立交叉引用自动化校验机制，检查所有引用的有效性。
- **二期内容**：一期文档中涉及二期功能时，仅用一句话概述并指向 [09-二期规划与远期增强](09-二期规划与远期增强.md)
- **Profile**：`full` = 三甲集群部署，`compact` = 基层单机部署，详见 [01-系统架构设计](01-系统架构设计.md#deployment-profiles)
