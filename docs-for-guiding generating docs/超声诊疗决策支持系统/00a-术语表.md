| emergency | 紧急安全更新 | 禁忌条件错误、严重安全漏洞 | 立即终止所有活跃会话，强制创建新会话 |
| safety_critical | 安全关键更新 | 禁忌条件新增/修改、高风险病种规则变更 | 旧会话保留已完成器官结论，新诊断使用新版本 |
| minor | 功能更新 | 新增知识条目、优化规则 | 会话内版本锁定，新会话使用新版本 |
| patch | 词条修复 | 术语修正、描述优化 | 热加载生效，不触发版本号变更 |

## 十三、多器官会话状态定义

| 状态 | 英文 | 说明 |
|------|------|------|
| pending | 未开始 | 会话已创建，等待开始 |

| terminated | 已终止 | 会话因安全更新等原因被终止 |
