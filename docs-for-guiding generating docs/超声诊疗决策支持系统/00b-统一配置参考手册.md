# 统一配置参考手册

> **最后核对：2026-09-28｜核对方式：从 `Settings` / `SGSettings` 模型直接导出默认值（可复现，见 §6）**
>
> **权威来源是代码**：`app/config/settings.py`（主服务，**280 个字段**）与 `safety_gateway/sg_config.py`（安全网关，独立进程）。
> **本文档与代码的一致性由 `tests/unit/sec/test_config_doc_consistency.py` 守护**——它登记了"SG 与主服务取值不同"的已知偏差，
> 并断言关键项的**代码值**（端口、RS256、日配额、会话上限、刷新有效期、P99 阈值、档位默认）。改这些值必须同步该测试与本文档。
>
> ⚠️ **本文档不写任何密钥的实际值**，只写字段名与"是否必须替换"。

## 1. 使用约定

| 项 | 约定 |
|---|---|
| 优先级 | **环境变量 > `.env` > 代码默认值**（pydantic-settings） |
| 环境标识 | `env='development'`（默认）；`production` 触发**启动强校验**（§2 与下条） |
| 部署档位 | `deployment_profile='compact'`（默认）/ `full`；**白名单校验**（`settings.py:428`） |
| 生产启动强校验 | 缺 `HSM_PRIVATE_KEY_PASSWORD` / `HSM_KEY_ENCRYPTION_KEY` / `REDIS_PASSWORD` → **直接拒绝启动**；`redis_url` 非 `rediss://` 仅告警（`settings.py:486-511`） |
| 端口冲突 | 不分环境，9 个端口去重校验（`settings.py:569-587`） |
| 启动入口 | `main.py` 启动链调 `validate_config()`，失败抛 `ConfigValidationError` |

## 2. 生产必须替换的字段（默认为空）

以下 17 个字段默认值为 `''`，**上线前必须提供**（否则对应能力静默失效或启动失败）：

| 字段 | 不替换的后果 |
|---|---|
| `database_url`、`postgres_password` | 无法连接主库（生产启动拒绝） |
| `jwt_secret_key` | ⚠️ 注意：JWT 实际由 **HSM 持钥签发**，此字段非签名密钥 |
| `redis_url`（默认 `redis://redis:6379/1`）、`REDIS_PASSWORD` | 生产校验要求 `rediss://` + 密码 |
| `vllm_default_model` | vLLM 档位无默认模型 |
| `minio_access_key` / `minio_secret_key` | DICOM 对象存储不可用 |
| `qdrant_api_key` | 主向量库不可用（`vector_index_auto_fallback=True` 会自动降级 pgvector） |
| `agnes_api_key` | RAG 的 LLM 增强静默禁用（`rag_use_llm_enhancement=False` 默认本就关闭） |
| `pacs_endpoint` | PACS 推送不可用（适配器默认 `local_fake`） |
| `object_storage_endpoint` / `_access_key` / `_secret_key` | 冷归档落到本地目录 |
| `security_officer_webhook` | 还原频告警**只落日志**（无安全官通知） |
| `alert_webhook_url` | 告警升级出站 webhook 静默跳过 |
| `alert_webhook_token` | 为空时告警回调端点**不校验**（内网语义）；建议生产配置 |
| `csp_policy` | CSP 为空 → 不注入 CSP 头（`SecurityHeadersMiddleware`） |

**默认值为占位地址、必须按现场替换**：`safety_gateway_host=localhost`、`llama_cpp_host=localhost`、
`vllm_host=localhost`、`minio_endpoint=localhost:9000`、`qdrant_host=localhost`、`bge_m3_host=localhost`、
`bge_reranker_host=localhost`、`ultrasound_clip_host=localhost`、`agnes_api_base=https://agnes-api.example.com/v1`、
`allowed_origins=http://localhost:3000,http://localhost:8080,http://127.0.0.1:3000`。

## 3. 部署档位差异（`compact` / `full`）

| 配置项 | compact | full | 覆盖逻辑 |
|---|---|---|---|
| `inference_engine` | `'llama.cpp'` | `'vllm'` | 强制覆盖 |
| `funasr_device` | `cpu` | 不覆盖 | 强制覆盖 |

## 4. 安全网关（独立进程）与主服务的差异 —— **已登记偏差**

| 项 | 主服务 | SG | 说明 |
|---|---|---|---|
| `db_query_timeout` | 5 | 2 | SG 快速拒绝 |
| `db_retry_max_attempts` | 3 | 2 | SG 少重试 |
| `db_retry_delay_base` | 0.5 | 0.1 | SG 快退避 |
| `db_retry_max_total_time_seconds` | 10.0 | 5.0 | SG 快速降级 |
| `safety_gateway_port` | 9001 | 9001 | 一致 |
| `sg_p99_latency_critical_threshold_ms` | 5.0 | 5.0 | 一致 |
| `deployment_profile` | compact | compact | 一致 |

## 6. 导出全量清单（保证与代码同步）

```bash
python -X utf8 -c "
from app.config.settings import Settings
for n, f in Settings.model_fields.items():
    print(f'{n} = {f.default!r}')
"
```

安全网关侧同理：`from safety_gateway.sg_config import SGSettings`。

> **约定**：本文档只维护"操作性关键项 + 生产必改项 + 档位差异 + 已知偏差"；
> **完整 280 项清单以导出命令为准**，不逐条抄写（抄写必然腐化）。

## 7. 维护约定

1. **新增配置项**：若属于"生产必改/安全相关/档位相关"，必须补进本文档对应小节；
2. **修改关键项取值**：必须同步 `tests/unit/sec/test_config_doc_consistency.py` 的断言与 `CONFIG_MISMATCH_ITEMS` 登记；
3. **SG 与主服务取值不一致**：必须登记进该测试的 `CONFIG_MISMATCH_ITEMS` 并写明"为什么短/长是合理的"，
   否则被当作缺陷；
4. 文档引用的取值一律标注"来自代码导出"，**不写"应该"、"建议为"这类无依据措辞**。
