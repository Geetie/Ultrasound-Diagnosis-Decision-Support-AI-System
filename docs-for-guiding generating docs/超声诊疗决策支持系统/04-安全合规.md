## 3. 密钥与签名（HSM）

**模块职责**（`security/hsm/`）：`manager.py` 门面（`:37-131`）、`degradation_manager.py` 降级阶段、
`persistence_manager.py` Redis 持久化、`key_manager.py` 密钥生命周期、`encryption_service.py` 签名/加解密、
`soft_hsm_manager.py` SoftHSM 生命周期、`crypto_algorithms.py` 算法提供方注册表、`task_scheduler.py`、`enums.py`。

**槽位**（`enums.py:19-28`）：`JWT_SIGNING` / `DATA_ENCRYPTION` / `DESENSITIZATION_MAPPING` / `EMERGENCY_SIGNING` / `REPORT_SIGNING`；
前缀路由 `jwt_/desens_/emergency_/report_`（`:69-89`）。

| 机制 | 实现 | 出处 |
|---|---|---|
| 通用签名 | **RSA-PSS + MGF1(SHA256)**，salt = MAX_LENGTH | `encryption_service.py:89-96` |
| JWT 签名 | PKCS1v15 | `:304-308` |
| 验签 | PSS，失败回退 `key_v{N}` | `:102-164` |
| 加解密 | RSA-OAEP(SHA256) | `:191-198,228-235` |
| 私钥导出 | `get_private_key` **恒抛 `RuntimeError`**（禁止导出） | `:314-327` |
| 轮换 | 版本 +1，旧键改名 `{name}_v{version}`，并行保留 `parallel_days=7` | `key_manager.py:129-202` |
| 自动轮换周期 | `jwt_key_rotation_days=120`、`desensitization_key_rotation_days=180`（compact 档均 60） | `settings.py:82,91-92` |
| 持久化加密 | 私钥 PEM 先 Fernet 加密（key=`HSM_KEY_ENCRYPTION_KEY`），PEM 再用 `HSM_PRIVATE_KEY_PASSWORD` 加密；**二者缺失即 `RuntimeError`** | `persistence_manager.py:158-159`、`key_manager.py:395-419` |
| meta TTL | 365 天 | `persistence_manager.py:155,163` |

**降级机制**：阶段 `NORMAL → CACHED → RESTRICTED → EMERGENCY`（`enums.py:11-16`、`degradation_manager.py:96-120`）；
阈值 `hsm_degraded_phase_1_threshold_minutes=5`、`phase_2=30`（`settings.py:89-90`）；
`DEGRADED_BEHAVIORS`（`enums.py:41-67`）：RESTRICTED 禁 JWT 签名、EMERGENCY 仅禁应急签名以外全部且 `max_signature_count=50`；
触发点：签名失败（`auth.py:59`）或公钥缺失（`:68`）→ `set_degraded()`。
降级状态 key `HSM_DEGRADED/_AT/_REASON`，TTL 7 天（`persistence_manager.py:193-200`）。

**SoftHSM**：`USE_SOFT_HSM` 为**环境变量**（默认 false，`soft_hsm_manager.py:35`）；过期 90 天 / 临界 120 天（`:31-32`）；
时间戳文件 `SOFT_HSM_TIMESTAMP_PATH`（默认 `soft_hsm_enabled_at.txt`，`:167`）；过期后签名/验签**抛错**（`encryption_service.py:69-70,119-121,273-274`）。

**应急签名**（`security/emergency_signing.py`）——多重要求同时满足才可用：

| 前置条件 | 值 | 出处 |
|---|---|---|
| 功能开关 | `hsm_emergency_signing_enabled` 默认 **False** | `settings.py:86` |
| 双人 | operator ≠ approver | `:61-64` |
| HSM 阶段 | ∈ {RESTRICTED, EMERGENCY} | `:70-72` |
| 已降级且持续 | ≥ 5 分钟 | `:74,78` |
| 日配额 | `hsm_emergency_signing_max_daily=50`，Redis Lua **原子**计数（Redis 失败回退**进程内非原子**计数） | `settings.py:87`、`:21-43,45-53` |
| 复核窗口 | `hsm_emergency_signing_verification_hours=24` | `settings.py:88` |
