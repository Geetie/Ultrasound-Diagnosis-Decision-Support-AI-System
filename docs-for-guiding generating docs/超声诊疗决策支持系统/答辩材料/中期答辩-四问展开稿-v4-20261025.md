## 0. 先修正一条设计原则

上一版我说"一页一句"，错了。正确的关系是**双通道分工**：

| 通道 | 带宽 | 谁接收 | 职责 | 密度 |
|---|---|---|---|---|
| **页面** | 高（可同时并置图表/数字/小字） | 眼睛，可回看 | **经得起回看**：口径、分母、证据、边界 | 可以密 |
| **口播** | 低（约 190 字/分） | 耳朵，只能顺序 | **给眼睛指路**：这一页该看哪里、说明它意味着什么 | 必须疏 |

由此得到两条硬纪律：

1. **页面上写全的话，嘴里不再念一遍。** 念页面是 3 分钟里最常见的浪费——它把高带宽通道降级成了低带宽。
2. **页面上写不出的判断（为什么这么选、为什么放弃），必须由嘴里说。** 这是口播唯一不可替代的内容。

所以 3 分钟不是 6 页也不是 11 页的问题，而是：**口播只走一条主线（约 500 字），页面按主线需要挂载证据，挂多少由证据密度决定。**

## 1. 四问 → 11 页的分配

| 根命题 | 页 | 页数 | 秒 | 这一问要立住的东西 |
|---|---|---|---|---|
| ① 我做的是什么 | P1–P3 | 3 | 36 | 3 秒说清品类；知道边界（**"不是什么"比"是什么"更可信**） |
| ② 意义 | P4–P5 | 2 | 31 | 缺口是真的；这件事现在可做且必须在这先做 |
| ③ 怎么完成 | P6–P8 | 3 | 45 | 方法有取舍；三器官非套壳；**验证方法本身可信** |
| ④ 进展 | P9–P11 | 3 | 53 | 做成了（带口径）；修正了（三次证伪）；还缺什么 |
| — | — | **11** | **165** | 缓冲 15s |

**节奏纪律**：11 页 = **10 次翻页**，平均 16.5s/页。超过 12 页，口播会被翻页动作切碎——**页数上限 12**。

## 2. ① 我做的是什么（P1–P3 · 36s）

### P1 · 封面 · 6s

| 项 | 内容 |
|---|---|
| 页面任务 | 3 秒内让评委知道品类与范围，不做悬念 |
| 标题 | **超声诊疗决策支持系统** |
| 副标 | 多模态 RAG · 甲状腺 / 肝脏 / 心脏 · **辅助**诊断 |
| 页面元素 | 一行状态条：`v1.3 · 94 接口 · 18 张表 · 今日在线`（用小字，不起眼但有信息） |
| 口播 | 「这是我做的系统，一套给超声医生用的辅助诊断工具。三分钟四个问题：它是什么、为什么值得做、我怎么做、做到哪了。」 |

> 页面密度：低。封面刻意留白，因为第一句话要靠人声压住场子。

### P2 · 它是什么：一条医生视角的线 · 18s

| 项 | 内容 |
|---|---|
| 页面任务 | 把"系统"翻译成"医生的一次检查"，让非技术评委也能建立画面 |
| 标题 | **医生的一次检查，系统介入 6 个动作** |
| 页面元素（**可以密**） | 横向 6 格流程条，每格：①缩略截图 ②动作名（开单 / 上传 / 判读 / 结论 / 报告 / 签发）③一行"医生此时要做什么"④一行"系统此时在做什么"。第 3 格高亮（唯一给结论的一步） |
| 口播（约 55 字） | 「不讲架构，讲医生怎么用它：开单、上传、等判读、看结论、出报告、签字，六步。系统只在第三步给结论，其余五步都在约束它。」 |
| 指屏 | 说到"第三步"时手点第 3 格，然后横扫后三格 |

> 这一页是全场信息密度最高的一页，也是**唯一一页允许放"小字"**。评委不会读全，但他会记住"六步、只有一步给结论"。

### P3 · 它不是什么 · 12s

| 项 | 内容 |
|---|---|
| 页面任务 | 用"边界"建立可信人格。**这是本科生答辩最容易被低估的加分项** |
| 标题 | **三个明确的"不"** |
| 页面元素 | 三行大字，每条下面一行小字理由：<br>① **不替代医生** —— 所有结论经医生确认后方可签发<br>② **不出最终诊断** —— 输出为"辅助建议 + 依据 + 不确定性"<br>③ **不是医疗器械** —— 现为科研验证阶段，无注册证 |
| 口播（约 45 字） | 「先把边界说清：不替代医生、不出最终诊断、现在也不是医疗器械。这三条不是免责声明，它们决定了后面每一个设计。」 |

> **为什么这页必须留**：它把"能力不足"转成"边界自觉"。后面 P10 讲证伪时，评委才不会觉得你在辩解——因为你一开始就说了自己到哪为止。

## 3. ② 意义（P4–P5 · 31s）

### P4 · 缺口是真的 · 18s

| 项 | 内容 |
|---|---|
| 页面任务 | 证明这不是"技术找场景"，是"场景缺技术" |
| 标题 | **超声的问题不在"看不清"，在"说不齐"** |
| 页面元素 | 三行表（现象 / 后果 / 系统对应动作）：<br>**术语异构**：同图不同描述 → 分级漂移 → 统一术语与计分口径<br>**依据不可追溯**：结论无出处 → 无法复核 → 结论带编号引用<br>**责任链断裂**：AI 说的谁负责 → 不敢用 → 强制医生确认 + 签名 |
| 口播（约 50 字） | 「三个缺口：术语不齐、依据不可追、责任链断。这三个都不是技术问题，是'敢不敢用'的问题。」 |

> **不要引任何"基层准确率 78%"之类的数字**。它在 `00 号` 里是待实测的立项基线，不是已测事实。

### P5 · 为什么是现在、为什么是超声 · 13s

| 项 | 内容 |
|---|---|
| 页面任务 | 回答"这事凭什么值得立项"（曦源评委必看） |
| 标题 | **现在可做，而且必须在这个场景先做** |
| 页面元素 | 左右两栏：<br>**左·技术条件**：多模态对齐可用 / RAG 可控 / 结构化输出可约束 / 小模型可私有化部署<br>**右·场景特殊性**：操作者依赖最强 / 术语最不统一 / 基层缺口最大 |
| 口播（约 40 字） | 「技术上，多模态和检索这两年第一次够用；场景上，超声是术语最乱、最依赖操作者的——可信问题在这里最先暴露。」 |

> 这一页的隐藏作用：**说明"为什么是我这个场景"而不是"为什么是做 AI"**。评委最烦"AI 医疗很热所以我做"。

## 4. ③ 我怎么完成（P6–P8 · 45s）

### P6 · 方法总览：一条链，四道约束 · 20s

| 项 | 内容 |
|---|---|
| 页面任务 | 一屏讲清架构，并让评委看见"约束型设计" |
| 标题 | **四条约束里，只有一条是模型** |
| 页面元素 | **扇出图**（真 N）：<br>影像 + 临床文本 → **三专科并行**（甲状腺 TI-RADS / 肝脏 LI-RADS / 心脏 LVEF）→ **融合层**（冲突检测 · 一致性 · Self-RAG · CRAG）→ **独立安全门**（同意 · 脱敏 · 禁忌 · 边缘，跨进程）→ **医生确认 · 签发**（HSM 签名）<br>图上用不同颜色区分"模型"与"约束" |
| 口播（约 55 字） | 「一条链四道约束：三专科并行判读、融合层互检、独立安全门、医生签发。四道里只有第一道是模型，后三道都是给它设的限。」 |

> **真 N 的讲法**：图上必须能看出"三路并行汇入融合"。如果评委问"并行有什么用"，答：**"融合层能互检的前提是至少两份独立结论；单路时那个校验是空的——这是我改架构的原因。"**（这句同时是 P10 第三条的伏笔。）

### P7 · 三器官不是套壳 + 抗幻觉防线 · 16s

| 项 | 内容 |
|---|---|
| 页面任务 | 证明定制深度；证明"抗幻觉"有具体装置而非口号 |
| 标题 | **三套分级体系，四道防线** |
| 页面元素 | **上半（表）**：三列对照<br>甲状腺：TI-RADS 计分（各项相加定级）· 置信度 `min(base+bonus,1)` · 多码冲突取最重<br>肝脏：LI-RADS 风险权重 · `0.5·base+0.5·risk` · 取最高风险码<br>心脏：LVEF 四档 · `base+0.1+0.1-0.1` · 取最低值（最保守）<br>**下半（条）**：四道防线——生成侧示例脱敏 → 解析前回显拒收 → 采集端过滤 → 输出守卫 |
| 口播（约 45 字） | 「三个器官不是换提示词：三套分级、三套置信度公式、三套冲突裁决。防线上，我在生成侧、解析前、采集端各设了一道。」 |

> 这页信息量最大，**口播只念"不是换提示词"和"三处设防"两句**，其余交给眼睛。评委扫一眼表格就能判断"他真的做了三套"。

### P8 · 我怎么知道自己没骗自己 · 9s

| 项 | 内容 |
|---|---|
| 页面任务 | 把"验证方法"本身当成一个成果（这是研究型答辩的加分点） |
| 标题 | **验证不是"跑通"，是每个数都带分母** |
| 页面元素 | 三个小卡：**67** 个审计探针（p0–p60）· **6,793** 个测试 · **87** 节台账（逐条 `path:line`） |
| 口播（约 30 字） | 「验证上我不看'跑通了'，我看每个数字的分母和口径——67 个探针随时能跑。」 |

> 9 秒，一口气带过。它的作用不是展开，而是**给 P9 的数字预先上保险**。

### P9 · 做成了什么 · 17s

| 项 | 内容 |
|---|---|
| 页面任务 | 用四个带口径的数字证明可运行 |
| 标题 | **四个数，每个都有分母** |
| 页面元素 | 四卡，每卡"大数字 + 口径两行"：<br>**0.9853** 真实知识库 136 条 gold，文档级命中 134/136<br>**1.34s** 判读调度 P50（**并行后重测值**，验收线 2.5s）<br>**11/11** 医生时序 9 步 + 2 条反证腿<br>**0.7961** 病灶分割 DSC，TN3K 614 张，256 输入 |
| 口播（约 50 字） | 「检索 0.9853、判读 1.34 秒、全流程 11 项全通、分割 0.7961。四个数，每个都写了分母和口径。」 |

> ⚠️ **真 N 后必须重测 P50**。并行会改变时延，用旧的单专科数字会被抓。若来不及重测，这一格改成"三路并行 P50 ××s（待测）"，**不留旧数**。

### P10 · 修正了什么 · 22s（**全场重心**）

| 项 | 内容 |
|---|---|
| 页面任务 | 三次证伪，三次改设计。把"踩坑"变成"方法" |
| 标题 | **三次证伪，三次改的是设计不是代码** |
| 页面元素 | 三行表（层面 / 原以为 / 实测 / 改了什么）：<br>**模型**：公开集 0.895 可用 → 换来源 **0.4929**（n=614）→ 公开集分数不作临床证据，建患者级验证集<br>**数据**：输出差=模型不行 → **608/620 照抄示例（98.1%）**，指标三口径只差 0.03 → 三道防线 + 指标降级<br>**系统**：多智能体并行→融合能互检 → 融合要 ≥2 份结论，单路时恒空 → **改为真 N 并行** |
| 口播（约 85 字） | 「第一次，模型层面：公开集 0.895，换个来源掉到 0.49。第二次，数据层面：620 条真结论里 608 条在照抄我的示例，指标本身也测错了对象。第三次，系统层面：融合要求两份独立结论，我只给一份——所以我没加功能，改的是架构前提。」<br>（停 1 秒）<br>「三次都不是失败，是三个错误的假设被换掉。」 |
| 指屏 | 说"改的是架构前提"时，手从 P10 第三行**移回 P6 的扇出图**——这个动作把两页缝在一起，是全场唯一的"回指" |

> **这一页的口播是全场唯一值得背下来的段落**。其余可以看页面说，这段必须抬头说。

### P11 · 还缺什么 + 收尾 · 14s

| 项 | 内容 |
|---|---|
| 页面任务 | 证明可完成；给出具体请求；留一句个人化的收尾 |
| 标题 | **代码侧没有欠账，欠的是三样数据** |
| 页面元素 | 左：`125 条功能 / 99 完成 / 6 条卡在数据`<br>中：三卡点（患者级独立验证集 · 指标口径定稿 · 评测规模）<br>右：一行请求「需要合作医院真实病例」 |
| 口播（约 70 字） | 「125 条完成了 99 条，剩下 25 条里 6 条卡在数据——真实病例、医生勾选、独立验证集，这三件不在我一个人手里。半年下来我最大的收获不是写完这套系统，是**知道自己什么时候会错**。谢谢。」 |
| 收尾动作 | 说完"谢谢"**站住 2 秒**，不立刻转身 |

> 最后一句选"知道自己什么时候会错"，而不是"请多指教"。**它是 P3（边界）与 P10（证伪）的合拢**——三个问题一个答案，评委记住的就是这一句。

## 8. 与 v3 的差异（便于对照）

| 项 | v3 | v4 |
|---|---|---|
| 叙事骨架 | 主张→语境→资质→取证→反驳→主张（论证式） | **四问驱动**（是什么/意义/怎么做/进展） |
| 页数 | 6 | **11**（上限 12） |
| 设计单位 | "一页一句"（错） | **双通道**：页面密、口播疏 |
| 真 N | 待定 | 已定，P6 扇出 + P10 第三条闭环 |
| 收尾 | 请求真实病例 | 请求 + **"知道自己什么时候会错"** |

> 论证式的内核没丢——它藏在 P10 与 P11 的最后两句里。**四个根命题是"讲什么"，论证是"怎么讲"**，两者不冲突。
