## 零、总问题与因果结构

### 总问题

> **医学 AI 辅助诊断的「临床效用」无法被证明。**

| 层面 | 原话/证据 | 后果 |
|---|---|---|
| **监管** | NMPA：「本产品提示结果不能代替活检结果，临床医生不能仅凭本产品结果进行临床决策」（国械注准 20253210557） | 不敢批 |
| **支付** | 医保局：「尚无独立的医疗服务产出、辅助诊断质量效用难以确定」（2024-11-20） | 不敢付 |
| **临床** | 4 位资深专家读 80 个结节，Fleiss κ 仅 **0.321–0.411**（PMID 31741167） | 医生不敢用 |

### 关键证据：不一致不是水平问题，是依据无法对齐

> **开会统一口径能把 κ 从 0.32–0.41 提到 0.57–0.62（P<0.01），但准确率一点没涨（AUC 0.677 → 0.632，n.s.）**
> —— *Endocrine* 2020，PMID 31741167

这一条**排除了"让医生多沟通"这条替代解法**，把靶心从"提高准确率"移到"让依据可对齐"。

**P4 的两处关键措辞（用户已确认方向）**
- 不是"没法量 → 全量复现评测"，而是「**没法量 → 设计一套衡量标准**」
- 不是"不可信 → 三元标注"，而是「**不可信 → 设计一套证据链**」

**研究方法的正确理解**
不是技术栈清单（bge-m3 / CRAG / Self-RAG 那是技术路线），而是**科研策略**：
| 方法 | 回答什么问题 | 产出什么证据 |
|---|---|---|
| 定量评估 | 指标口径差异从哪来 | 同数据多种口径的对比表 |
| 代价敏感分析 | 误判方向该怎么计权 | net benefit 曲线 |
| 结构审计 | 知识库结构缺什么 | 结构体检报告 |
| 消融实验 | 哪个因子影响最大 | 单因子变化曲线 |
| 数据审计 | 数据本身可不可信 | 口径标注规范 + 审计结果 |
| 案例研究 | 真实场景下能不能用 | 落地验证结果 |
