# PPT 视觉风格方案（待选）

> 三个方案，你选一个。选定后我按它做全部 9 页。

---

## 方案 A · 深色技术风（archify 原生风格）

**参考**：archify 的默认配色 `DESIGN.md`

```
背景     #020617  接近纯黑
面板     #0F172A  深蓝黑
主文字   #FFFFFF  纯白
次文字   #94A3B8  灰蓝
边框     #1E293B  深灰蓝

强调色（按组件类型分）
前端     #22D3EE  青
后端     #34D399  绿
数据库   #A78BFA  紫
安全     #FB7185  珊瑚红
```

**字体**：JetBrains Mono / 等宽字体

**适合**：技术答辩、评委里有工程背景
**风险**：**投影仪上深色背景会发灰**，学术答辩通常不建议。后排看不清。

**我的评价**：不推荐。这是给显示器看的配色，不是给投影仪的。

## 方案 B · 学术白底风（academic-pptx 规范）

```
背景     #FFFFFF  纯白
主色     #1F4E79  深海军蓝（标题）
强调     #2E75B6  中蓝（小标题/高亮）
正文     #2D2D2D  近黑
次要     #777777  灰（引文/注脚）
分割     #CCCCCC  浅灰
警示     #C00000  暗红（仅用于负结果/缺口）
```

**字体**：单一无衬线（PingFang SC / 微软雅黑）

**规则**：
- 白底黑字，投影最稳
- 最多三色
- **不要**标题下装饰线
- **不要**装饰性图标
- 左侧图、右侧解读
- 每页至少 30% 留白

**适合**：跨专业评委、投影环境不确定
**风险**：朴素，不够“现代”

**我的评价**：**推荐**。中期答辩评委是跨专业的，可靠比好看重要。

---

## 方案 C · 我们的现状（深蓝灰 + 暗红）

```
背景     #FFFFFF
主色     #1F2937  深蓝灰
强调     #991B1B  暗红
```

**问题**：这个配色是 deck-engineer 自己定的，没有任何依据。`#1F2937` 是 Tailwind 的 gray-800，`#991B1B` 是 red-800——**是拿来即用的调色板色，不是为学术答辩选的**。

**我的评价**：介于 A 和 B 之间，但没有 B 的规范依据。

---

## 建议

**选 B（学术白底）**，理由：
1. 中期答辩跨专业评委，投影环境不确定，白底最稳
2. academic-pptx 是 1,383★ 的学术演示规范，有依据
3. 三色限制让页面干净，信息密度才能靠内容而不是装饰

**但 B 需要改一件事**：它的默认强调色是中蓝 `#2E75B6`，对“缺口/负结果”不够刺眼。我建议：
- 一般强调用中蓝
- **负结果/缺口/断点用暗红 `#C00000`**

## 需要你定

1. **A / B / C 选哪个？**
2. **如果选 B，强调色用中蓝还是暗红？** 我建议两个都用：中蓝做结构高亮，暗红只标问题。
3. **要不要保留现在的“左侧竖色轨”？** 那是 deck-engineer 加的装饰，academic 规范里没有。
