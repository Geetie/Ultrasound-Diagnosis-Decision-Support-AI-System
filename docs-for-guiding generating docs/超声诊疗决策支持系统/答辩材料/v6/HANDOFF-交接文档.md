## 2. 大纲（9 页，已定稿）

### 总问题与因果结构（全案骨架）

> **总问题：医学 AI 辅助诊断的「临床效用」无法被证明。**

三个层面同时卡住：
- **监管**：NMPA「临床医生不能仅凭本产品结果进行临床决策」
- **支付**：医保局「尚无独立的医疗服务产出、辅助诊断质量效用难以确定」
- **临床**：专家间一致性仅 κ 0.321–0.411（PMID 31741167）

因果树：
```
总问题：效用不可证明
├─ ① 没有衡量效用的指标（RAG 指标无方向标量）
├─ ② 依据不可核查（88.5% 单块、无 evidence_level）
├─ ③ 关键判断不稳定（高风险档 43.33%，n=60）
└─ ④ 底层数据不可信（620 条里 608 条照抄示例）
```

**① ②是"没法量"，③ ④是"量出来的东西不可信"。**
