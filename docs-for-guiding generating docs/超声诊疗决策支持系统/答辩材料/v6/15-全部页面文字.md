## P8 · 问题与计划

```
08 / 09 · 问题与计划

四个卡点，四条下一步

─────────────────────────────────────────────────

卡在哪（按性质分）

① 指标层   现有指标不分方向
   157 篇综述里 89.2% 只做离线，没有一篇按误判方向分层
   → 答不了"这个系统让漏诊多了还是少了"

② 结构层   依据存不下来
   88.5% 文档只有一块，知识块里没有证据等级字段
   → 检索到了指南，也说不清这条推荐是几级证据

③ 生成层   同样输入，输出会变
   同引擎两次生成，高风险档一致率 43.33%（n=60，门限 95%）
   → 医生看到的分级可能取决于运气

④ 数据层   测量基础不成立
   620 条历史判读里 608 条照抄示例，干净集只剩 157 条
   → 在这批数据上算的指标都不作数

─────────────────────────────────────────────────

下一步

① → 建风险分层评测矩阵，157 条真实判读 + 人工标注定口径
② → 补证据等级字段，按指南层级重建切分
③ → 换 structured_outputs，再用 TI-RADS 规则独立重算校验
④ → 重建干净评测集，双人盲标 + 一致性检验，目标 480 例

─────────────────────────────────────────────────

落地：与复旦合作医院　先回顾性验证　再前瞻性（伦理批件后）
```
