# 答辩页面重写（叙述版）

> 原则：**每个数字前面必须有判断句，后面必须有"这意味着什么"。**
> 反例（现状）：`κ 0.321–0.411 一致性系数` —— 评委得自己悟
> 正例（本版）：`这个一致性水平，临床上不足以支撑统一判断`

# P2 · 研究背景（一）：这个问题不是靠"多沟通"能解决的

**页面标题（action title）**：`同一个结节，专家之间都读不到一块去`

```
┌──────────────────────────────────────────────────────────────┐
│ ① 专家之间的分歧，比想象的大                                   │
│                                                              │
│    κ = 0.321–0.411                                           │
│    4 位资深专家 / 80 个结节 / 4 套 TIRADS 盲法                 │
│    Endocrine 2020, PMID 31741167                             │
│                                                              │
│    → 这个一致性，临床上不够用。同一个病人换一家医院，可能换    │
│      一个结论。                                               │
├──────────────────────────────────────────────────────────────┤
│ ② 而且不是"沟通不够"——开会统一口径，一致性上去了，准确率没动    │
│                                                              │
│    κ 0.32–0.41 → 0.57–0.62（P<0.01）                         │
│    但曲线下面积 0.677 → 0.632（不显著）                        │
│                                                              │
│    → 分歧不是态度问题，是大家手里的判断依据本身对不齐。多开会   │
│      解决不了。                                               │
├──────────────────────────────────────────────────────────────┤
│ ③ 代价是真的，而且能算                                        │
│                                                              │
│    2,297,057 例甲状腺癌中，1,736,133 例属过度诊断（75.6%）      │
│    63 国 385 个登记处 / 2013–17 / 中国女性 >85%                │
│    Lancet Diabetes Endocrinol 2024, PMID 39389067            │
│                                                              │
│    → 四分之三的甲状腺癌被"查出来"了，但按现在的诊断标准，这些   │
│      本来不该被发现。过度诊断的代价是手术、终身服药、心理负担。  │
├──────────────────────────────────────────────────────────────┤
│  靶心不是"提高准确率"，是「让判断依据可对齐」                    │
└──────────────────────────────────────────────────────────────┘
```

**为什么这样写**
- 每块都是「**判断句 → 数据 → 这意味着什么**」三段式
- ①的判断是"分歧比想象大"，数据 κ 只是论据，箭头后是**后果**（换个医院换个结论）
- ②的判断是"不是沟通问题"，数据是前后对比，箭头后是**排除了一条替代解法**
- ③的判断是"代价能算"，数据是过度诊断比例，箭头后是**代价的具体形态**（手术、服药、负担）
- 三段递进：有多大分歧 → 为什么不是沟通 → 代价是什么

**不引用**：医生缺口 5/13/15 万（调研确认无可靠出处，被问就说"公开口径互相矛盾所以不用"）

## 改完的对比：同一个数据，两种写法

| | 旧版（错） | 新版（对） |
|---|---|---|
| 形式 | `κ 0.321–0.411 一致性系数` | `专家之间的分歧比想象的大` → 数据 → `换个医院可能换个结论` |
| 评委感受 | 这数什么意思？ | 哦，这问题严重 |
| 问题 | 只放数据，不做叙述 | 判断在前，数据作论据，后果在后 |

**我犯的错**：把所有调研到的数据都堆上去，以为数据多就是信息密度高。实际上**没有解释的数据是噪音**——评委要在 3 分钟里自己悟出含义，等于没讲。
