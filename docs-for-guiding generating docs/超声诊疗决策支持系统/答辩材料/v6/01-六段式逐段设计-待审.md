## 第二段 · 研究背景与意义（35 秒）

**这段要回答：为什么值得做？**

**页面上有什么**（三块，自上而下）
1. **临床场景**：超声是甲状腺、肝脏、心脏筛查的一线手段；基层医院超声医生少，单人单机，多数没有上级审核岗。
2. **现实困难**：同一个结节，不同医生的描述和分级可能不一致；AI 给的结论缺少可追溯的依据，医生不敢用。
3. **研究问题**（用一句话框住）：**怎么让 AI 给出的辅助结论，基层医生敢参考、能核对、说得清依据？**

**口播（约 155 字）**：
「超声是甲状腺、肝脏、心脏筛查最常用的一线手段。但基层医院的现实是，超声医生少，一个人一台机器，多数没有上级审核。同一个结节，不同医生的描述和分级常常对不上。AI 能给出结论，可医生不敢信——因为不知道这个结论是怎么来的。所以我的研究问题是：怎么让 AI 给出的辅助结论，基层医生敢参考、能核对、说得清依据。」

**注意**：这段**不引用任何"医生缺口 XX 万"的宏观数字**。那些数字来源不一、口径混乱，一被追问出处就露馅。用临床场景本身说话。

## 第三段 · 研究内容与方法（50 秒）

**这段要回答：我具体做了什么？怎么做？**

**页面上有什么**（一张架构图，横向从左到右）
```
超声图像 + 文本
      ↓
  ① 知识底座        指南 / 共识 / 典型病例  →  知识库（1101 个知识块）
      ↓
  ② 检索增强        混合检索（向量 + 关键词）→ 98.53% 命中
      ↓
  ③ 专科判读        甲状腺 / 肝脏 / 心脏 三个专科智能体
      ↓
  ④ 安全网关        独立服务，结论出站前强制校验
      ↓
  医生确认（最终决定权在医生）
```
图下面一行小字标注：**辅助工具，不替代医生诊断**。

**口播（约 225 字）**：
「我的做法分四层。第一层是知识底座，把超声的诊疗指南、专家共识和典型病例整理成一个可检索的知识库，现在有一千一百多个知识块。第二层是检索增强，医生提问后，系统先用向量和关键词两路混合检索，找到最相关的依据，命中率是百分之九十八点五三。第三层是专科判读，甲状腺、肝脏、心脏各有一个专科智能体，按各自的诊断标准出结论。第四层是安全网关，这是一个独立部署的服务，所有结论在送到医生面前之前必须过一遍，涉及禁忌和高风险的内容会被拦下来。最后一步由医生确认，系统只做辅助，不做最终诊断。」

**为什么这样排**：评委看架构图就知道工作量，看四个编号就知道你思路清楚。这一页是「研究内容与方法」的骨架，也是评分表里「课题独立性」的落点。

## 第五段 · 存在问题与后续计划（25 秒）

**这段是中期答辩的必备项，也是最能体现态度的地方。**

**页面上有什么**（左右两栏）

左栏「目前存在的问题」：
- 评测数据不够：现在 169 条评测样本，目标是 700 条，还差得多
- 还没有真实临床病例验证：目前所有验证都在测试数据上完成

右栏「下一步计划」：
- 扩充评测集到 700 条，补足独立病例
- 对接真实临床数据，请医生做一轮人工复核
- 补齐三个器官的定量测量功能

**口播（约 115 字）**：
「目前还有两个短板。一是评测数据量不够，现在一百六十九条，目标是七百条。二是还没有用真实临床病例验证过，目前的结果都是在测试数据上得到的。下一步我计划先扩充评测集到七百条，再对接真实病例请医生做人工复核，同时补齐定量测量这部分功能。」

**为什么必须主动说**：中期答辩评委最在意的就是「进度是否可控」。**主动说问题 + 给出计划**，比藏着掖着强得多。藏着不说，评委一问就变成"他自己没意识到"。

## 需要你确认的四个点

1. **架构图画四层还是三层？**
   我写的是「知识底座 → 检索 → 专科 → 安全网关」四层。但代码里安全网关是独立部署的旁路，不算"层"。画四层好看，画三层更准确。**你倾向哪个？**

2. **「三个专科智能体」这个说法行不行？**
   代码里三个器官的专科都在（`thyroid.py`/`liver.py`/`cardiac.py`），但实际调用时按器官只走一个。说「三个专科智能体」没问题（确实有三个），但**不能说「三个同时并行工作」**。

3. **第五段的问题要不要再加一条？**
   除了"评测集不够""没做临床验证"，还有一条更硬的：结论到证据的对应关系只通到条目 ID（展开区已挂载），来源文档/页码快照还没做。这条要不要说？说了显坦率但很伤。

4. **要不要「文献综述」这一页？**
   曦源中期门槛原文第一项就是「完成文献综述」。现在六段式里没有这一页。要单独加一页，还是在第二段里带一句？

## 附：我这次的不同

上次我提「三个负结果」「证伪」「判断力」，那是**论文答辩**的思路，不是中期答辩的。

中期答辩的评委要看的是：**这个学生知道自己在做什么研究、做到哪一步了、后面打算怎么走**。所以这版的主线不是"我推翻了什么"，而是"**我建了一套系统，建到哪了，接下来怎么补**"。

数据全部真实（554 提交、8225 测试、86.30% 覆盖率、98.53% 检索命中、1101 知识块、91 接口、17 张表），每一条都能在仓库里查到。
