## 页面字的三条规矩

**① 能断行就断行，别写段落**
```
✗ 换一家医院，同一个病人可能拿到另一个结论，这说明一致性不足
✓ 换一家医院
  同一个病人可能拿到另一个结论
```

**② 数字独立成行，字号放大**
```
✗ 一致性 κ 只有 0.321–0.411，属于中等偏低
✓ κ = 0.321 – 0.411     ← 28pt
  四位资深专家 · 八十个结节 · 四套 TIRADS   ← 14pt
```

**③ 用符号代替连接词**
```
✗ 也就是说，虽然一致性提升了，但是准确率并没有提升
✓ 话能说一样，判断不能
```
```
✗ 曲线下面积从 0.677 提升到 0.632，但是不显著
✓ 曲线下面积 0.677 → 0.632，不显著
```

## 页面信息密度检查

P2 一页有四块：κ 数据 / 开会对比 / 过度诊断 / 落点句。

**为什么能装下**：
- 每块平均只有 **3 行**（数字 1 行 + 注 1 行 + 结论 1 行）
- 字号分级：数字 28pt、结论 18pt、注 14pt
- 大量留白，块与块之间有分割线

**评委扫读路径**（从上到下 3 秒）：
```
κ 0.321–0.411  →  开会也没用  →  75.6% 过度诊断  →  所以要可核对
```

**这条路径必须通顺**。如果评委只看大字号能读出逻辑，页面就合格。
