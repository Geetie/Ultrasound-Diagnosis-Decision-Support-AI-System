## 第二部分：Ultrasound-CLIP 的问题（你点名的）

我查到了，而且比我想的严重得多。

### 事实一：ULC 在部分临床属性上判别力低于随机基线

`app/inference/attribute_hints.py:60-63` 的 `DISABLED_REASON` 写得很直白：

```python
"InternalCharacteristics": "实测 +0.143 弱于基线，增量不足不上产品"
"PosteriorAcoustics": "实测 +0.045（基线 0.843 本身极高），无区分度"
"Vascularity": "实测 −0.056 低于多数类基线，模型在该维无判别力"
```

**「血流」这一维的实测值是 −0.056，低于多数类基线**——意思是在这一维度上，模型还不如一律猜「最多的那一类」。

这是 `app/config/settings.py:509` 记录的 A.21 全量实测（US-365K 71,919 张）：
- ULC 9 维宏平均 **0.6894**
- BiomedCLIP **0.4092**（低于多数类基线 = 无判别力）

**医学多模态模型在关键临床属性上是瘸的。** 这是真问题。

### 事实二：多模态检索能力远低于论文宣称

`16号:1377-1381` 的 A.21 全量重测（71,919 对，官方 test split）：

| 模型 | I2T R@1 | R@5 | R@10 |
|---|---|---|---|
| ULC 官方权重（保守口径） | 0.0518 | 0.1800 | **0.2768** |
| BiomedCLIP base | 0.0004 | 0.0019 | **0.0038** |
| 论文 ULC 完整模型（含图融合） | — | 0.2359 | 0.3745 |

**BiomedCLIP 的 R@10 是 0.0038**——几乎等于随机。ULC 去掉图融合后 0.2768，比论文的 0.3444 还低。

### 事实三：指标体系本身会骗人

同一节记录的「口径事故」：

> A.19 记录的 "I2T@10=97.8%" **作废**，因为该数字来自 **500 对抽样**（占官方 test 71,919 对的 0.7%）。500 对的随机下限是 0.2%，模型几乎必中；71,919 对的随机下限是 0.0014%。**小样本把指标放大了约 350 倍。**

### 这三条合起来才是真正的研究问题

> **医学多模态模型（以 Ultrasound-CLIP 为代表）在真实规模评测下，能力远低于论文宣称；而且评测口径本身就能把结果放大 350 倍。那么：在什么条件下，这类模型才值得接入临床辅助链路？**

这个问题：
- 不是我编的，是项目实测撞出来的（0.6894 / 0.4092 / −0.056 / 0.2768 / 0.0038 / 350 倍）
- 不是通用 RAG 问题，是**医学多模态模型的特有问题**
- 尚未解决（本项目只是测出来了，还没给出判定准则）

**我认为这才是真正该作为研究内容的东西。比我原来那三个都实。**
