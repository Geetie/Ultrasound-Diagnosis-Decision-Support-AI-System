**研究方法这一栏的正确理解**（这是你指出我错的地方）
不是"用了什么技术"，而是"**用什么研究策略回答研究问题**"：
- **定量评估**：多个指标口径在同一批数据上对比，看差异从哪来
- **对照实验 / 消融**：改一个因子看指标变化
- **结构审计**：对知识库结构做体检，而不是只看检索结果
- **数据审计**：建立口径标注规范，判断数据本身是否可信
- **代价敏感分析**：借医学的 DCA/net benefit 工具接 RAG 评测

口播（175 字）：我的总问题是，医学 AI 辅助诊断的临床效用没法被证明。监管说不能仅凭它做决策，支付方说效用难以确定，医生则认为它的依据对不上。这个总问题由四个成因导致。第一，没有能衡量效用的指标——现有的 RAG 指标是不分方向的标量，把良性判成恶性、把恶性判成良性，算出来是一回事。第二，依据不可核查，知识库 88.5% 的文档只有一块，结构里连证据等级字段都没有。第三，关键判断不稳定，分级约束解码在高风险档只有 40.88%。第四，底层数据不可信，六百多条历史判读里六百多条是照抄示例。研究方法上，我用定量评估对比口径、用消融实验看单因子影响、用结构审计和数据审计建立可信基础。
