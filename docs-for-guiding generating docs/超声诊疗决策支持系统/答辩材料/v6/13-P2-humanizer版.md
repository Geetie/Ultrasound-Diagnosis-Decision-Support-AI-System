## 改了什么

| 改前 | 改后 | 为什么 |
|---|---|---|
| 「不是态度问题，是判断依据对不齐」 | 「分歧不在嘴上，在各人手里那把尺子上」 | 去 negative parallelism，换成画面 |
| 「① 专家之间的分歧，比想象的大」 | 「四位资深专家，八十个结节，四套 TIRADS 标准。」 | 少用判断句当小标题，直接给事实，让读者自己感到 |
| 「→ 这意味着：临床上不够用」 | 「这个数字的意思是：换一家医院，同一个病人可能拿到另一个结论。」 | 去箭头符号，用完整句子说人话 |
| 「代价是真的，而且能算」 | 「这种对齐不了的代价，是可以算出来的」 | 「真的」是填充词，删 |
| 「靶心不是"提高准确率"，是...」 | 「问题不出在"不够准"。出在依据对不齐。」 | 拆两句，去对称结构 |

## 语言上的具体选择

**用「有人会说」而不是「可能有人认为」**——前者是口语，后者是论文腔。

**用「那就让他们开会。研究里真这么做了」**——两个短句，有转折。比「通过召开共识会议的方式」自然。

**用「大家把话说得一样了，看病的水平一点没提高」**——大白话。评委一听就懂。

**用「分歧不在嘴上，在各人手里那把尺子上」**——这是画面，不是抽象判断。人记得住画面。

**数字后面加「占 75.6%」而不是前面加**——先说绝对数让人有量级感，再给比例。

**保留引号用直角引号「」和双引号""混排**——中文排版习惯，不是 AI 那种全篇直引号。
