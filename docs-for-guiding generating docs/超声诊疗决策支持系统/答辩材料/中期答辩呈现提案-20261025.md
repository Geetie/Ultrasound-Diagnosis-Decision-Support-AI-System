## 1. 最影响说服力的一件事（只改这一件）

**把"我做了个系统"换成"我验证了一件事，并且证伪了三件事"。**

推荐的中期命题（一句话，可直接当副标题）：

> **在超声辅助诊断里，"模型分数高"和"临床上可信"是两件事。我做了一套系统，专门用来把这两件事分开测量——中期最重要的产出，是我证伪了自己三个假设。**

为什么这句能救场：它把现有的一堆"缺陷修复记录"重新解释成**实验结论**，把"系统做太大"从减分项变成"实验平台"，并且天然回答评委最想问的"你一个本科生凭什么做完这么多"——因为你的贡献是**判断**，不是堆代码。

## 2. 叙事主线（四段式，不是时间线）

| 段 | 作用 | 评委脑子里的问题 | 你给什么 |
|---|---|---|---|
| 钩子（20s） | 建立"为什么难" | 这题有什么可研究的 | 一个具体的临床错判场景 |
| 交付（50s） | 证明你真做出来了 | 是不是纸上方案 | 一张架构图 + 一句"它已经跑通全流程" |
| 证伪（60s） | **中期最值钱** | 你验证了什么 | 三个负结果，各一句结论 + 一句处置 |
| 收口（30s） | 说明后续可完成 | 剩下半年你干什么 | 剩余卡点 + 需要什么支持 |

主线一句话：**"做出来了 → 于是能测了 → 一测发现三件事不是我以为的那样 → 所以下半程改做这三件事。"**

## 4. 六屏结构（每屏：页面任务 / 结论式标题 / 证据 / 时长）

### P1 封面 · 20s
- **结论式标题**：让超声 AI 从"说得像"到"证得清"
- **副标题**：一套可被验证的超声辅助诊断系统 · 中期汇报
- **画面**：一张真实判读结论截图（`TR2 … 证据: [1], [2]`），不要装饰性插画
- **台词锚点**："这不是演示视频，是今天还在跑的系统。"

### P2 问题 · 25s
- **结论式标题**：基层最缺的不是"AI 给个结论"，是"敢不敢按下签发"
- **画面**：三行对照——医生要什么 / 模型给什么 / 中间缺什么
- **必须出现的一个具体场景**：同一张甲状腺图，不同医生给的描述术语不一致 → 检索与分级都跟着漂。`A`（01/13 号文档 + 术语表现状）

### P3 系统 · 40s
- **结论式标题**：一条从影像到签发的闭环，五道关卡
- **画面**：单页架构图（可用 `docs-for-guiding generating docs` 下 system-map 的 4 张流程图之一，已过视觉检查）
  1. 影像与临床文本 → 2. 混合检索（BM25+向量）/ 知识库 1257 块 → 3. 1+N 专科智能体（甲状腺/肝脏/心脏）+ 融合层（冲突检测 / Self-RAG / CRAG / 分层校验）→ 4. 独立安全门 → 5. 医生确认与签发（HSM 签名）
- **口播只讲一句**："五道关卡里，只有第 3 步是模型，其余四步都是给它设的约束。"——这句话最能体现架构思想。

### P4 证据 · 与 P3 同屏或紧接 · 合计 40s

### P5 三个负结果 · 45s（**中期核心页**）
- **结论式标题**：我证伪了三件事，因此知道下半程该做什么
- **排版**：三行，每行"原以为 / 实测 / 因此"

| # | 原以为 | 实测（`A`） | 因此 |
|---|---|---|---|
| 1 外部效度 | 公开集 AUC 0.895，模型可用 | 换一个来源（TN3K, n=614）AUC **0.4929**，接近随机 | 公开集分数不能当临床证据，必须建患者级独立验证集 |
| 2 指标效度 | 忠实度低 = 模型爱编 | 三种口径只差 0.03（0.0906 / 0.1258 / 0.0836），根因是"结论里的影像所见本来就不在知识库里" | 这个指标测错了对象，已降级为诊断指标、改主指标 |
| 3 实验方法 | 加图谱邻居能提召回 | 先在原评测集测得"零增益"，再一查发现评测集本身饱和（129/136 已命中 top-1）；换自造难集后召回确实 +15pp，但排序转不成收益 | **先证明尺子能测，再下结论**；扩边判定不做 |

- **必须补的一句**（防止被读成"没做成"）："这三个结论都不是失败，它们分别改掉了我一个错误的实验设计。"

## 8. 最可能被问的 5 个问题（答法骨架）

1. **"这么多代码，是你一个人写的吗？"**
   → 结论：主体是我，工具是 AI 辅助，但**判断与验证是我做的**；证据：67 个探针与 6,673 个测试是"防我自己骗自己"的装置。边界：设计稿与部分前端组件有协作。
2. **"可用病例只有几十条，你的结论站得住吗？"**
   → 结论：站得住的是**方法与机制**，不是**疗效结论**；这正是我把 AUC 0.895→0.493 摆出来的原因。缺的证据已列成清单。
3. **"3 分钟讲三个负结果，是不是没做出东西？"**
   → 结论：反了——负结果是我能给出**可复跑证据**的部分；正向成果在 P3/P4。
4. **"和商用超声 AI 比，你的优势是什么？"**
   → 结论：不比模型大小，比**可验证性与安全约束**（五道关卡里四道是约束、零静默门禁、病人隔离闭环）。边界：无注册证、无多中心数据。
5. **"剩下半年做什么？"**
   → 结论：三件——患者级独立验证集（等数据）、指标语义定稿（等拍板）、评测规模（等临床使用）。已做成可直接送决策的一页纸。
