**本轮质量债期间修掉的三类真实缺陷**（均为"静默失败"，只查埋点写入方发现不了）：

1. **任何直方图的 p99 恒为 None**——`_calculate_histogram_p99` 假设 `hist._buckets` 是 dict，
   而依赖已升级为 prometheus-client 0.25.0（是列表），异常被 `except: pass` 吞掉；
   看板 4 个 p99 面板自上线起一直空白，且"算不出来"与"没有样本"表现完全一样。已修并改为留痕。
2. **带标签直方图的 p99 永远取不到**——`diagnosis_latency`/`multi_organ_latency` 由 `labels(...)` 产生，
   桶计数在子指标上，父对象为空。已修（合并子指标）并加读取侧守卫。
3. **CI 盲区**——`.gitignore` 的 `data/` 是无锚点模式，把 `tests/unit/data` 与 `tests/integration/data`
   整目录忽略，导致 **3 个既有测试文件从未进入仓库、CI 从未运行过它们**（本地覆盖率因此虚高于 CI）。
   已修 `.gitignore` 并新增守卫 `tests/unit/quality/test_test_files_are_tracked.py`。
