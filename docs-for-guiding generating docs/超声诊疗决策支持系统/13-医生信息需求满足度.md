## 2. 逐项说明

**M1 切面标准性评估**：`PlaneAssessment` 含切面类型、`plane_score ∈[0,1]`、问题与可见结构；
经 `monitor.py` 与导航 WS 下发到前端逐帧呈现。**关键语义**：前端把"切面无数据"与"切面不合格"
**区分显示**（`PlaneStatusBadge` 有专门用例），避免把"没查到"当成"不合格"。

**M2 快速路径高危标记与自动升级**：边缘快速路径命中高危时触发升级建议，
需医生经 `/api/v1/diagnosis/{request_id}/confirm-upgrade` 确认；自洽性由
`nav_auto_upgrade_*` 校验（`settings.py:446`）。**真机部分**（边缘端触发）🔬。

**M3 自动测量**：`knowledge/measurement_extract.py` 从 LLM 输出抽取测量项
（三维尺寸/纵横比/距离），`Measurement.pixel_spacing_source` 默认 `"default"`——
即**未拿到像素间距时按默认值换算**，此为已知精度限制（见 §3）。

**M4 鉴别诊断**：`knowledge/differential.py`（`parse_differential_diagnoses`）产出**排序清单**，
`DifferentialDiagnosis.rank ≥1`、`confidence ∈[0,1]` 有范围约束。

**M5 恶性概率**：`MalignancyRisk.probability ∈[0,1]`，并附**依据（Basis）**；
前端仪表盘展示概率 + 档位标签，展开可见每条特征贡献与出处。

**M6 图像质量**：`edge/image_quality.py` 产出分项分数，`ImageQuality.overall_score ∈[0,1]`；
前端浮层展示分项。

**M7 转诊/处置**：`knowledge/clinical_actions.py` 给出动作、科室与**触发条件**（前端逐条列出）。

**M8 报告模板库**：`app/templates/report/` 下 4 套模板（`.md`），报告草稿生成时选用。

**M9 后方回声**：`posterior_acoustic` 字段已贯通「协议 → 专科解析 → 接口 → 模型」8 个文件；
但因依赖 UDAF（超声描述属性框架）词表与术语映射质量，另有 `vocabulary.py` 的
`TODO(Phase0A)`（UHAT 四级层级、术语审核流、未映射队列）**尚未完成**。

**M10 患者话术**：`knowledge/patient_explanation.py`；注意与 M7 的区别——
M10 面向**患者可理解表达**，不得直出分级术语。

**M11 科研指标**：`knowledge/research_metrics.py` 输出可科研化指标；
无真实队列时其数值仅有形式意义。

**M12 跨模态对照**：`knowledge/cross_modality.py` 给出跨模态提示；属二期增强范围
（见 `09-二期规划与远期增强.md`）。

## 4. 维护约定

1. 新增医生信息需求时，在本表追加 `M13+` 行，并**必须**给出：需求来源、后端落点、
   前端呈现、验证方式（测试路径或现场验证项）；
2. 状态只允许 ✅ / 🟡 / ❌ / 🔬 四值，**不得使用"基本完成"等模糊措辞**；
3. 标 ✅ 的项必须能在代码中找到落点且**至少有一条测试或前端组件**支撑；
4. 本表是"医生侧信息完整性"的唯一来源，接口字段变更若影响本表，须同步更新
   `03-接口规范.md` §5。
