> **最后核对：2026-09-28｜核对方式：指标口径沿用旧版（未与需求方逐条复核，标注为"待确认"）+ 实测值现场核对**

## 1. 项目定位

面向超声科医生的**诊疗决策支持系统**：从 DICOM 影像与临床文本出发，经三类专科智能体
（甲状腺/肝脏/心脏）推理，由融合层（冲突检测 + 一致性校验 + Self-RAG + CRAG）产出
分级结论与证据链，并强制人工复核机制；全程满足数据脱敏、审计可追溯与患者知情同意要求。

**部署形态**：`compact`（边缘/单机，llama.cpp + CPU 语音）与 `full`（服务器，vLLM + GPU）两档，
差异覆盖项见 `06-开发环境与进度规划.md` §4。

## 5. 口径说明（避免误读）

1. **"文档说完成"不等于"运行期生效"**：本项目已多次出现"能力已实现但未接线"
   （指标导出、告警回调、前端双通道 WS，见 `05` §2.4/§4.4 与 `08` §2.4）。
   因此本文档的"实测状态"列只接受**可复现的证据**（测试数字、报告文件、代码位置）。
2. **样本量决定结论有效性**：`phase0a_report.json` 的 `passed=false` 是真实未达标，
   但 6 例本身也不足以证明"不达标"——两项都不能作为验收结论，必须重测。
3. **指标口径的权威性**：若临床/产品方给出新的目标值，请直接修改本文档第 2 节并在
   `10-架构优化与修订记录.md` 登记变更理由与影响面。
