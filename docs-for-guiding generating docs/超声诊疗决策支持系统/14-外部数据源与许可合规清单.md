# 外部数据源与许可合规清单

> **最后核对：2026-09-28｜核对方式：联网检索 + 代码引用核对（未下载数据样本）**
>
> **本文档是数据来源与许可的唯一来源。** 旧版 `07-数据标注与模型评估.md` 曾把 Ultrasound-CLIP 微调写成
> "以未落地外部模型为前提"——**该前提已不成立**：`US-365K` 已于 2026-04 开源（详见 §2.1）。

## 1. 结论摘要（先看这一节）

1. **`US-365K` 已开源**（36.4 万超声图文对），原"主方案待外部模型"的判断作废；可通过 HF 镜像获取（见 §4.1）。
2. **甲状腺方向没有任何"可商用"的公开数据集**：TN3K/TG3K 为 CC BY-**NC**，TNSCUI 为 CC BY-**ND（禁止演绎，连微调都不允许）**，CINECLIP 许可未注明。
   → **一期注册用的甲状腺训练/验证数据必须来自自有或合作医院数据（或购买授权）**；公开集仅可用于研发期算法预研与内部评测。
3. 心脏与肝脏有可商用数据（`CACTUS` CC BY 4.0、`CARDIACUDC`/`ECHOCP` Apache 2.0、`AUL` CC BY 4.0）。
4. **权威总入口**：`ultrasound-open-access.nidusai.ca`——96 个超声数据集策展目录，可按**模态/临床用途/许可**筛选，可导出 CSV，每条带 SonoDQS 质量分级。建议将其 CSV 快照纳入版本库作为数据源台账。
5. 多器官分割训练数据可用 `UltraSam / US-43d`（43 个公开集聚合，28 万+ 图像-掩膜对，仓库含转 COCO 脚本）一次性获取。

## 3. 许可红线（**注册申报必读**）

1. **禁止演绎（ND）不得用于训练**：`TNSCUI` 为 CC BY-ND 4.0，训练/微调会构成演绎作品 → **只能用于评测或不用**。
   TN3K/TG3K 为 CC BY-**NC** → 仅限非商业研究用途。
2. **需签协议的数据不能进注册材料**：EchoNet 系列、BUS Dataset B/UDIAT 等需签署研究使用协议，
   其条款通常限定"非商业研究"，**不得作为注册提交的验证数据**。
3. **商用许可是必要条件而非充分条件**：使用 CC BY 4.0 数据仍需在注册材料中给出
   数据来源、许可证明与标注过程记录（可追溯性矩阵需登记到具体数据集与版本）。
4. **SonoDQS 分级可作为质量筛选依据**：策展目录为每条数据给出 Platinum/Gold/Silver/Bronze/Steel 分级，
   建议在数据台账中记录该分级。
5. **本清单不构成法律意见**：正式申报前须由合规/法务逐份确认许可原文与最新状态
   （策展目录为缓存快照，条目状态可能滞后）。

### 4.2 建议的采集方式

```bash
# HF 数据集走镜像（HuggingFace 主站不可达）
export HF_ENDPOINT=https://hf-mirror.com
python -c "from huggingface_hub import snapshot_download; ..."
```

- 本机已具备依赖：`huggingface_hub`、`datasets`、`requests`、`pydicom`、`numpy`（均已安装）。
- **当前策略：先只拉小样本验证管线**（TN3K 子集 + US-365K 少量图文对），
  确认 `app/embedding/busi_adapter.py` 类适配器与 `scripts/evaluate_ultrasound_clip.py` 能跑通后再批量获取。
