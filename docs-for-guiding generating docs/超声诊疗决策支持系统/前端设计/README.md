## 交接用：设计数据包

[`设计数据包/`](设计数据包/README.md) —— 给**其他 Agent / 工程师**按数据实现与还原用（Figma2code 式交接）。

内容：`screens.json`（15 屏机读索引 + 高度账 + 条件渲染证据）· `tokens/`（CSS 变量 + W3C DTCG JSON，含 dark/light 双模式）· `assets/svg/`（2 个真实图标 + 实例）· `参考图/`（15 张 2x PNG，仅比对用）。

入口是 [设计数据包/README.md](设计数据包/README.md)，里面写了映射规则、antd 接线注意、**哪些"缺失"是正确的**，以及三处证据的验收方法。
