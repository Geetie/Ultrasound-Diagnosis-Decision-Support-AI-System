# ⛔ 先读这个：17 个画布帧 = 3 个路由 + 1 个组件 + 1 个主题变体 + 2 个文档板

> **不是所有帧都是前端页面。** 这是本包最容易误用的一点，所以单独成文件、放最前面。

---

## 一、实现面只有 4 个（不是 17 个）

| # | 实现对象 | 类型 | 对应画布帧 |
|---|---|---|---|
| 1 | **工作列表页** | 路由 `/`（或 `/worklist`） | `01_工作列表`（深色）+ `15_工作列表浅色`（**同一页的浅色主题，不是第二个页面**） |
| 2 | **设置页** | 路由 `/settings` | `08_设置` |
| 3 | **新建检查会话页** | 路由 `/session/new` | `09_新建检查会话` |
| 4 | **检查工作区** | **一个组件 / 一个路由**，有 11 个视图状态 | `02` `03` `04` `05` `06` `07` `10` `11` `12` `13` `14` |

**也就是说：15 个"页面帧"里，真正要写的页面只有 3 个 + 1 个工作区组件。**

---

## 二、逐个帧的定性（照 `_overview.json` 的 `role` 字段）

### ✅ `role: "page"` —— 真前端页面（3 个）
| 帧 | 路由 | 说明 |
|---|---|---|
| `01_工作列表` | 工作列表页 | 一级导航第 1 项；进行中会话置顶 + 行内「继续」 |
| `08_设置` | 设置页 | 一级导航第 2 项 |
| `09_新建检查会话` | 新建会话页 | 建会话：患者 / 设备 / 部位预设 |

### 🧩 `role: "workspace-state"` —— **工作区的状态，不是页面**（11 个）
| 帧 | 是工作区的哪个状态 |
|---|---|
| `02_扫查态` | 扫查态（默认沉默） |
| `03_等待分析中` | 冻结后等待（进度两个词） |
| `04_判读态结论` | 结论态（看一眼档） |
| `05_多部位态` | 扫查态 + 部位指示条出现 |
| `06_停档禁忌命中` | 结论态 + 「停」档覆盖式 |
| `07_报告侧面板` | 结论态 + 报告侧面板滑出（draft） |
| `10_确认动作区` | 结论态 + 确认动作区出现 |
| `11_AI不可用态` | 结论态的 AI 不可用变体 |
| `12_签发后` | 结论态 + 已签发（状态行出现） |
| `13_诊室遮蔽态` | 结论态的遮蔽变体 |
| `14_多部位标签排` | 结论态 + 部位标签排出现 |

> **这 11 个共用同一套骨架**（常驻条 40 / 影像区 600 / 结论区 260 / 确认动作区 60），
> 差异只是**少数节点的显隐与文案**。`_overview.json` 里每帧的 `diff_from` 标了它相对哪个基准帧、
> `design_data.json` 里每个节点带 `cond`（渲染条件）与 `missing_by_rule`（故意不渲染的元素）。
> **正确做法：写一个 `WorkspacePage` 组件 + 一套视图状态，不要写 11 个页面。**

### 🎨 `role: "theme-variant"` —— **同一页的另一个主题，不是页面**（1 个）
| 帧 | 说明 |
|---|---|
| `15_工作列表浅色` | `01_工作列表` 的浅色版。**与 01 逐节点对照：只有颜色变、布局一个像素没动。** 实现时换 `data-theme="light"` 即得，**不要写第二套页面** |

### 📄 `role: "doc-board"` —— **文档性质的板，绝对不要实现**（2 个）
| 帧 | 是什么 |
|---|---|
| `B1_读图指南板` | 给评阅人看的读图说明（区域定义 / 颜色图例 / 规则 / 屏一览） |
| `B2_页面与跳转总览板` | 按钮去向往返表 |

> 这 2 个**不是界面，是说明**。它们的元素数据仍导出在本包里（`design_data_for_agents/`），
> 但每个根节点带 `do_not_implement: true`。**照它们做界面是错上加错。**

---

## 三、一句话总结

```
17 个画布帧
├── 3 个前端页面        → 01 / 08 / 09
├── 1 个工作区组件      → 02 03 04 05 06 07 10 11 12 13 14（11 个状态）
├── 1 个主题变体        → 15（= 01 的浅色）
└── 2 个文档板（禁做）  → B1 / B2
```

**实现面 = 3 个路由 + 1 个组件 + 1 次换肤。**
