## 一、为什么现在的数字不可靠（诊断）

| 问题 | 现状 | skill 怎么说 |
|---|---|---|
| **单次划分** | T2b 用 80/19/17 单次 | k-fold (5-10) 是强制要求 |
| **test 太小** | T2b test 仅 17 个视频 | 小样本必须 CV，否则方差大 |
| **图像级划分** | TN5000 / TN3K / AUL 都只能图像级 | 医疗数据应按患者/视频分组（GroupKFold） |
| **无外部验证** | 全在同一机构/同一公开集上测 | "external validation on data from a different institution is expected" |
| **无分层报告** | 只有总体指标 | "report metrics stratified by age, sex, ethnicity, disease severity" |
| **无失败模式分析** | 只报均值 | "characterize where the model fails and how gracefully" |
| **类别不平衡未处理** | TN5000 恶性 71.5%，未加权 | 给了三种策略（加权/焦点损失/WeightedRandomSampler） |
| **增强安全性未审** | 用了 `preprocess_train`（RandomResizedCrop） | 给了哪些增强对医疗影像不安全 |
