### 第 2 步：手写条目 + **立刻验证**（这一步我上次漏了）

每条必填：
```json
{"query_id": "zh-ret-XXX",

```

**写完立刻跑校验**（**血泪教训：不跑这一步，我上次 47 条里 74% 的 chunk_id 标错**）：

```bash
PYTHONPATH=~/uai/src ~/uai/venv/bin/python scripts/audit/p117_gold_uniqueness.py \
    --dataset <新文件> --kb-version kb_v2.1.0
```

**p117 查三条**：
1. 引文 ≥15 字
2. 引文命中 chunk 数 ≤5（否则辨识度不足）
3. **引文必须真的在标注的 (doc_id, chunk_index) 里** ← 这条能抓出 74% 那类错

### 第 3 步：过 p79 四道闸

```bash
python scripts/audit/p79_dataset_quality_gate.py --dataset <合并后> --kind retrieval
```
闸门：重复率 0 / 模板 ≤10% / 影像术语 ≥50% / 自相矛盾 0

## 四、质量标准（每条都要满足）

| 项 | 要求 | 理由 |
|---|---|---|
| **引文长度** | **≥15 字** | 短片段在多个 chunk 都有，gold 不稳定 |
| **引文唯一性** | 命中 chunk ≤5 个 | 超过说明这句在库里太泛 |
| **chunk_id 一致性** | `quote in chunk.content` 为真 | 否则 gold 指向无关的块 |
| query 长度 | 15-40 字 | 太短像关键词，太长不真实 |
| notes | 必须写，说明临床场景 | 审计时能看懂为什么这样问 |

## 六、为什么不能脚本批量生成

1. **p79 有「模板 ≤10%」闸**：脚本拼的 `"{organ} {术语} {问法}"` 会直接撞闸
2. **用户明确要求**：「数据集的构造必须一条一条深思熟虑地撰写，不得用脚本」
3. **临床真实性**：真实疑问来自「医生查房时到底会问什么」，模板产不出

**工具（p116）只提供候选引文，不生成问题。**
