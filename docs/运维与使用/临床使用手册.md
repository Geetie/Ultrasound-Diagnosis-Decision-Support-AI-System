# 临床使用手册

> **状态：框架（骨架）**。面向超声医师与技师。内容以**实际界面流程**为准
> （`frontend/src/pages/*`），法规声明与适应范围以最终注册文件为准。
>
> **核心声明**：本系统为**辅助工具**，输出不构成诊断结论。所有结论必须由执业医师复核后使用。

## 1. 它能做什么、不能做什么

| 能做 | 不能做 |
|---|---|
| 提示当前切面是否标准、图像质量是否足够 | 替代医师判断图像能否用于诊断 |
| 给出自动测量（长径/短径/前后径/纵横比/体积等）与尺寸来源 | 保证测量值与真值一致（受像素间距与切面影响） |
| 给出鉴别诊断清单、恶性概率、处置建议（含目标科室与紧急度） | 给出最终诊断或治疗方案 |
| 按器官模板生成结构化报告，支持签发与推送 | 代替医师签署报告（签发需医师操作并留痕） |

## 2. 一次完整检查的流程

1. **新建/选择会话**（检查主界面）：确认患者、设备与目标器官。
2. **知情同意**（知情同意页）：未签署或已撤回时，系统**拒绝展示 AI 结论**并明确提示；
   撤回会即时生效（含取消在途分析）。
3. **采集与导航**：图像角落显示**切面状态**（标准/预警/未知）与**图像质量提示**
   （无提示/警示/严重）。高危标注以橙色闪烁边框区别于普通标注，并自动升级为深度分析。
4. **提交诊断**：提交后系统跳转到**诊断结果页**（携带请求标识，自动等待并展示结果）。
5. **阅读结果**：结果页按「结论 / 鉴别诊断 / 处置建议 / 科研指标 / 依据溯源」组织。
6. **出报告**：结果页底部「打开报告」→ 报告页生成草稿 → 签发 → 推送 PACS/HIS。

## 3. 结果怎么读（避免误读的关键点）

- **AI 置信度 ≠ 恶性概率**：两条概率条含义不同、来源不同，界面刻意分开显示，**不可互相替代**。
- **恶性概率**应结合分级（低/中/高）与依据贡献阅读，不可只看数值。
- **鉴别诊断**按可能性降序，卡片内含"支持/排除依据"；请优先核对排除依据。
- **依据溯源**含推理路径、知识库引用与**跨模态对照**（CT/MRI/病理提示）。
- **安全提示必须阅读**：幻觉警示、质控徽标、图像质量提示任一出现时，
  应先处理提示再采信结论。
- **完整性未通过的报告不要签发**：报告页会列出缺失段落（如"测量摘要"），
  请回诊断页补录后再生成。
- **患者解释话术**（若展示）标注为「非正式报告内容」，**默认不进入正式报告**，
  仅在您选择并确认后方可向患者说明。

## 4. 反馈与修正

在「反馈提交」页记录 AI 结论的偏差（原因、修正值）。修正会被统计为**修正率监控**，
用于按方向（AI 偏高/偏低）与按医师维度发现系统性问题；
达到阈值会触发告警，请如实填写而不是"为了指标好看"。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 结果页一直等不到结果 | 确认是从检查页/语音提交进入（需带请求标识）；超时后可用「重试」重新拉取 |
| 提示 AI 输出被拦截 | 同意状态为未签署/已撤回/纯报告模式；先完成同意流程 |
| 报告无法推送 | 未签发的报告不可推送（避免无签名内容进入病历）；先签发 |
| 签名校验未通过 | 报告正文可能已被改动；核对内容后重新签发，勿强行推送 |
| 测量值可疑 | 检查是否缺少像素间距（回退路径会标注尺寸来源）；必要时手工测量 |

## 6. 待补章节（需临床与注册确认后填写）

1. 适应范围与禁忌（含人群限制）。
2. 各器官的**推荐操作规范**与屏幕示例截图。
3. 培训与考核要求、使用权限与账号管理流程。
4. 不良事件上报路径与联系人。
