## 三、差距分析

### 3.1 未达成目标清单

| 目标          | 要求        | 现状    | 差距     | 严重程度 |
| :---------- | :-------- | :---- | :----- | :--- |
| **术语映射覆盖率** | ≥95%      | 75.3% | -19.7% | 🔴 高 |
| **心脏用例有效性** | 100%含预期属性 | 0%    | -100%  | 🔴 高 |

### 3.2 问题根因分析

#### 问题1：术语映射覆盖率不足（75.3%）

**表现**：解析器未能识别部分医学术语，导致`missing_attribute`错误占全部失败的100%

**根因**：

- 词汇表覆盖范围有限
- 部分复合医学术语未收录（如"边界尚清"、"回声减低"等）
- 位置描述词汇不完整

#### 问题2：心脏用例缺少预期属性

**表现**：216例心脏用例的`expected_attributes`均为None，全部被SKIPPED

**根因**：

- 心脏诊断属性体系尚未完善
- 心脏超声报告结构与甲状腺/肝脏差异较大
- 缺乏标准化的心脏属性词汇映射
