## 1. 范围与用途

本软件为**超声诊疗决策支持系统**：在超声检查过程中提供切面标准性提示、自动测量、
鉴别诊断、恶性概率、图像质量提示、处置建议与结构化报告，**不作出最终诊断**，
所有输出均标注为辅助信息并需执业医师复核。

**预期用途边界**：仅用于辅助执业医师，不用于自主诊断、不用于儿科/孕产妇（除非另行评估）、
不作为唯一决策依据。

## 4. 功能需求（按模块归集）

> 每类给出**验收方式**：`[离线]` 自动化测试可验证；`[真机/数据]` 需现场或数据集；
> `[人工]` 需评审或现场操作确认。具体需求 ID 与锚点见 D1。

| 模块 | 需求归集 | 验收方式 |
|---|---|---|
| 导航链路 | 切面标准性评估与状态提示、图像质量分级提示、高危标注触发自动升级 | `[离线]` 编排与判定逻辑测试；`[真机]` 实际帧率与提示正确率 |
| 测量与特征 | 自动测量（长径/短径/前后径/纵横比/体积、到包膜与皮肤距离）、后方回声特征 | `[离线]` 换算与回退逻辑；`[真机]` 像素间距与真值误差 |
| 诊断输出 | 鉴别诊断清单、恶性概率（独立于 AI 置信度）、处置建议、跨模态对照 | `[离线]` 结构与规则；`[数据]` 准确率与一致性 |
| 报告 | 按器官模板生成、完整性校验、签发（HSM 签名）、推送 PACS/HIS | `[离线]` 模板/完整性/签名校验；`[真机]` PACS/HIS 联调 |
| 患者沟通 | 患者解释话术（默认不入正式报告） | `[人工]` 话术评审 |
| 科研与监控 | 科研量化指标、修正率监控、漂移检测、灰度路由 | `[离线]` 计算与告警；`[数据]` 分布漂移实际触发 |
| 安全合规 | 三层脱敏、审计哈希链、患者同意（含撤回 500ms 内生效）、密钥管理 | `[离线]` 全部安全逻辑；`[真机]` SoftHSM |

## 5. 非功能需求

| 类别 | 需求 | 当前证据 |
|---|---|---|
| 性能 | 端到端延迟满足各档位 P99 目标（realtime/standard/full） | `[真机]` 未验证；离线侧由 `scripts/bench_suite.py`（纯函数热路径 + 并发放大倍数 + 显存维度）提供回归基线 |
| 可靠性 | 安全网关不可用时降级为拒绝输出（E4005B），不静默放行 | `[离线]` 已有测试 |
| 可用性 | 单实例故障不影响既有会话；备份与恢复演练 | `[人工]` 需演练记录 |
| 安全 | 密钥不落盘明文；审计链可校验完整性；密钥轮换支持断点续跑 | `[离线]` 已有测试；`[真机]` SoftHSM 全链路 |
| 可维护性 | 覆盖率门禁（整体 ≥80%、核心 ≥90% 目标）；静态检查阻断 | 见 D6（整体已达标，核心 84.42%） |
| 隐私 | 上传前去除 PHI（DICOM 标签级去标识化） | `[离线]` 已有测试（含失败开放语义的显式记录） |

## 6. 待确认项（需人工决策，勿由开发单方决定）

1. **脱敏失败是否拒绝入库**：当前实现为"失败开放"（解析失败返回原始字节且照常保存）。
   若法规或风险分析要求"失败即拒存"，需变更需求并配套修改测试与流程。
2. **核心覆盖率目标**：90% 目标下剩余缺口多为真机项（见 D5），需确认是否以
   "离线可达上限 + 现场验证"口径替代纯数字门禁。
3. **报告推送范围**：推送 PACS/HIS 的字段集合与是否包含患者解释话术（当前不入正式报告）。
4. **软件安全分级**（IEC 62304 A/B/C）与对应的文档深度要求。
