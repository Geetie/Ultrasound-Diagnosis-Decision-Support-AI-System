## 测试体系重建（按设计文档原文口径，用人话写明白）

### 背景纠偏（为什么重规划）

1. **双引擎的真实目的**（01 号文档 §5.1/§5.7 原文）：`compact` 档（基层 RTX 3060）用 llama.cpp+量化，`full` 档（三甲）用 vLLM+fp16——两个引擎是**两种部署档位的后端**，一致性验证的目的是"**同一病例在两种部署形态上结论等价**"+"**量化部署不劣化**（量化幻觉增量 ≤0.5%）"，不是"双医生会诊"。此前的会诊叙事作废。
2. **合成 780 例重新定位**：作为精度验收无效（无金标准、非真实分布），降级为 CI 机器回归；分层框架（常规 200/边界 400/高风险 100）本身来自 07 号文档，保留框架但换真实数据。
3. **两条已触发的原设计处置规则**（此前被忽略）：

- I2T@10=23.6% < 37% 门槛 → **立即降级 bge-m3-medical 纯文本检索为主检索方案**（Top10 ≥88%），图像腿降为实验性
- A3 量化幻觉增量 6.41% > 0.5% → **切换 Q8_0 量化重测**（原设计：不达标换更高精度量化）
- 一致率 80.38% < 90% → 原设计条款"统一使用单一推理框架"，Q8_0 重测后再判定

### 重建后的测试矩阵（每项写明：数据 / 指标 / 怎么测 / 过关线）

**T0 部署等价性评测（原口径重写，数据=已有三轮逐例结果，不重跑）**

- 指标（01 号 §5.7 原文口径）：①语义分级一致率 ≥98%（"4"与"4a"同类算一致）②完整文本一致率 ≥90% ③量化幻觉增量 ≤0.5% ④边界差异率（Gate 0A 阶段一点估计 ≤3%）
- 怎么测：重算三轮报告（同模型 Q4_K_M vs fp16，780 例，temp=0）；补"预期 vs 实际边界跨越检测"（expected_grading 字段已有）；按条件性门控出正式判定
- 过关线：如上四条；不过 → 执行处置（Q8_0 重测 / 单一框架声明）

**T0b 量化等价性重测（处置执行）**

- 数据：780 例合成回归集（仅作回归用途）+ Q8_0 GGUF（约 8.5GB，hf-mirror）
- 指标：同 T0 四条
- 过关线：量化幻觉增量 ≤0.5%；仍超 → Q8_0→单一框架声明

**T1 知识库 + RAG 标准评测调优循环**

- 数据：知识库语料=甲状腺/肝脏/心脏公开指南与共识文本（目标甲状腺 ≥150 份文档，Gate 1 要求）；golden set=US-365K 真实 caption 抽 200 条作查询 + 半自动相关 chunk 标注（重排分数+人工抽检 50 条）
- 指标：检索层 Recall@5/10、MRR、nDCG@10（定义：相关文档被召回进 Top-K 的比例/首个相关结果排名倒数均值/分级相关性折扣排序）；生成层 faithfulness（答案论断可追溯占比）、context precision/recall（RAGAS 口径）
- 怎么测：建库 → golden 查询逐条检索 → 算检索指标 → 引擎生成 → RAGAS/人工抽检 50 条校准；调优变量=chunk 大小/overlap、BM25+dense 权重、rerank top-k、K 值，每改动跑同一查询集 A/B
- 过关线（设计文档数字）：混合检索召回率 ≥90%（Gate 0）、纯文本 Top10 ≥88%（降级方案）、检索准确率 ≥85%（Gate 1）；通用参考线 Recall@K≥80%、MRR>0.7、nDCG@10>0.85

**T2 真实数据集精度评测（第一梯队，全部现成公开数据集）**

- T2a 甲状腺良恶性（TNSCUI，4,554 张真实图+标注，CC BY-ND 仅评测）：BiomedCLIP 图像嵌入 → 近邻标签投票判良恶性 → 与真实标注比：**敏感性、特异性、PPV、AUC**（07 号定义：敏感性≥95%、特异性≥85%、PPV≥85%、AUC≥0.90 为最终目标；本轮为**基线测绘**，产出真实数字+漏诊/误诊分解——开发验证阶段按 07 号允许"使用公开数据集补充，限制为基础辅助级别"）
- T2b 切面/质量（CACTUS 37,736 张+CARDIACUDC，真实标签）：`edge/plane_assessment.py`、`edge/image_quality.py` 模块输出 vs 真实标签 → 混淆矩阵 + Top-1 准确率
- T2c 端到端诊断（ALN-ULTRA，258 例真实图文+活检金标准，CC BY 4.0）：系统完整诊断 → 准确率/PPV + faithfulness；258 例每例都出三列对照（输入/系统输出/金标准）
- 过关线：本梯队**先出真实数字与差距分析**（这是此前完全缺失的），正式达标判定（≥89%）按 00 号文档须 Gate 0B 临床数据（≥200 例/器官），本轮明确标注

**T3 Gate 0A 边界验证集（原定义重建）**

- 原定义=分级落在 TI-RADS 3/4a/4b、LI-RADS 3/4、心脏 normal/mild/moderate 档位的病例每档 ≥100 + 置信度 ±0.05 内病例
- 怎么测：从 A2/A3 报告逐例数据重算（expected_grading 与置信度字段已有）→ 边界子集单独统计四项指标；真实分级标注病例归入 T2/数据决策项

**收尾**：16 号文档 A.2.2 + 10 号修订记录（双引擎定位修正为部署档位等价性）+ 豁免清单 + SKILL 回写 + git 提交
